# 原著推广漫画：拆话、分镜、节奏与叙事

本参考解决“**读者为什么继续看，且能真正看懂**”，不是固定多少格、套反转或保证流量。默认用于已有权改编、以吸引阅读原著为目标的静态多格漫画；创作者明确要求**完整讲完一个章节/故事**时，完整保留该范围的必要事件、情感与因果，即使这需要拆成多话、多页，不得因推广默认而只留片段。超出授权范围的后续章节另议。只要分析、分镜或提示词就停在用户指定阶段。

## 1. 找原文与设定范围

1. 读取创作者指定原著、版本、已选章节和相关前后文；记录文件/链接、章节及段落或行号。仓库不在当前分支时可只读准确来源；缺源、章节不明、权限不明或读不到时说明，不猜细节。只声称读过的范围。
2. 如果还没有选段，**选题而不是默认第一章**：在获准阅读范围内给2–3个有来源的候选，分别比较具体冲突、情绪体验、理解前置成本、适合的停点与剧透代价；指出推荐及理由。若用户只是把第一章当例子，不当作选定第一章。已选章节不自行换题。
3. 写一个简报：谁吸引什么读者、这是引流选段还是完整章节、从哪到哪、展示与保留什么、允许前置多少背景、交付到文本/提示词/成图的哪一步、分发和预算是否已授权。检查原著作者/改编权限；不可宣称授权已获或平台已发布。
4. 用原著把关系、年龄/时间、地点、动机、人物实际知情及秘密状态写清。明确区分**原文事实、角色猜测、旁白所知、改编表达、尚待确认**；不将猜测、指控或角色自述写成已证实事实。无证据的年龄/身份/事件先标待核，不补写。涉及敏感情节按创作者约定及平台有效规则处理，不将本次作品的具体年龄、关系或禁忌普遍化。

## 2. 从小说事件拆成连续的漫画话

按事件而非小说段落长度切分。先列本范围的**因果链**：起因/目标 → 行动 → 阻碍 → 反应/选择 → 后果 → 留下的新问题。尤其标出道具交接、对话答复、伤势和地点变化；每项标原著位置与可见/需交代的落点。哪些事实读者现在必须知道，哪些可延后，但不能删掉理解原因所需的信息。

再规划连续话，每话至少写：

| 项目 | 决策问题 |
|---|---|
| 承接入口 | 上话的人在哪里、正在做什么，哪个问题/事件未完成？首次入口说明必要背景 |
| 单话推进 | 本话主要矛盾、行动、阻力、人物反应与**发生了什么变化**？不是只有一段预告 |
| 情绪曲线 | 起始情绪 → 刺激/升级 → 反应或选择 → 落点；用动作、眼神、停顿体现，不全靠解说 |
| 本话兑现 | 给读者一条发现、一轮交锋、一个情绪结果或一次选择；不强制每话必须反转 |
| 出口/钩子 | 具体谁遇到什么问题、哪条信息未回答；标原著依据、是否透露答案及下一话实际从哪接 |
| 待续清单 | 每个事件继续/解决/明确暂缓，以及角色知情、关系、地点、持物和伤势的新状态 |

不预设“每章两话”或“每章十几话”。先拆到因果与情绪都看得懂，才能估数量；不足就增页增话，不能跳过冲突与结果。完整章节中可保留多个局部钩子，但最后一话仍须交代此章必要结果；下一章作为衔接或新一段承诺。推广片段可在约定位置停，但前面已经开始的行动/提问须接下去或在画面中明确暂缓。

**连续与独立是两种交付**：续话必须读取实际最新上话结尾，而不是靠大纲记忆。对每个上话待续事件逐一写“继续、解决、明确暂缓”及对应图文；暂缓不是解决。新选爆点若和正在讲的故事不同，只能说明它是独立选段、取得选择后再做，不能称为连续下一话。更强的钩子出现在下一章时，先读完整邻接上下文；推荐把下一章的顺序事件单独扩成续话，而非把未来结果无依据提前塞进既有成品。仅评价钩子时不擅自重做分镜或改图。

可复制结构见 [拆话与分镜模板](../assets/叙事拆话模板.md)；纯合成演示见 [拆话示例](../assets/叙事拆话示例.md)。规划表用于构思，不替代每话《漫画分镜.md》的唯一正文、事件ID及必要台词。

## 3. 首张、页、格：把心理和因果画出来

- **读者站在哪里**：首张抓一个有原著依据的处境/反差，让新读者知道“谁想做什么、遇到什么”；必要关系、时间和地点有辨识方式。第一人称开幕或人物介绍可按用户需要增加，但须有原著依据、采用角色当时所知，不泄露后文；不是固定必须加的前言。
- **先页职责，再选格数**：一页可以建立空间、完成一轮交锋、展示线索与反应、制造翻页等，按信息量、情绪重要性和实际文字空间决定格数、大小和方向。不是每页都重复同一网格，也不是每页必须大反转。明确同行左右、跨行上下的阅读顺序；特殊布局需单独标箭头或顺序。
- **单格一个可见瞬间**：同一格里可有同时发生的对视与握手，但“发现→离开→抵达”是先后动作，需拆格。动作、对象、结果、人物站位写具体。重要发现安排“物/现象→谁看到→反应或下一动作”，使情绪转变有证据；递物有接触与归属变化，暴力先后及结果不挤成同一时刻。允许留无字反应格，不为凑格数重复同一信息。
- **镜头为叙事服务**：建立关系/场景时用可辨站位的中远景；关键选择、证据、情绪可用近景或留白；空间或道具变化需要重新建立方向。镜别变化体现对比或节奏，不以“漂亮特写”代替信息。画面有答案就不重复写讲解，画面缺关键因果时用有来源的对白、内心或必要叙述，不以沉默掩盖缺漏。
- **先完整写，再安排字**：直接对白要标说话人及对象；内心标主体，叙述标身份，画外声标来源。文字原样引用或明确标注改编；不捏造角色口吻、删减导致关系失真或提前揭露。朗读检查谁先说、答复接什么、为何改变主意；超过自然留白就拆格/页或调整构图，不暗缩字或删关键句。实际是否显示名签、气泡或白框按该项目最新要求。
- **逐格交接**：每格至少写来源、信息、画面、衔接、无字提示词与完整 `TEXT-*`；每页写职责。统一参考风格只统一人物与世界，不抄参考图剧情；每页明确实际需传哪个角色参考及顺序，尚未生成或未确认不称定妆。成页提示词包含场景、各镜头、角色、文字留白与不画字；是否有能力单次生成成页需实测，素材图不等于成品页。

## 4. 钩子不是只截断一句话

先确定已兑现什么，再提出**读者能具体回答“我想知道什么”**的缺口。常见类型是决定与后果、身份/事实的核对、关系是否改变、危险如何化解、承诺能否兑现；选择与本话卖点匹配的一种，不必每话都用同一种。可先回答一个小问题再引出更大的问题。

逐项检查：①原著确有该处境及依据；②观众知道人物为什么在意；③本话已给真实内容而非只有预告；④未把“不讲动机/漏掉半场戏”伪装成悬念；⑤不将疑点当确认、未突破剧透边界；⑥下一话有自然承接及可信兑现。标题可强调冲突，但不能承诺漫画中没有的背叛、死亡或结局。比较钩子时可说明情绪、悬念、需前置的信息及剧透代价，不声称某一方案必爆。

若创作者认为完成稿钩子弱：先核成品停点与原文下一段，区分**现有成品内换停点**、**连续加新话**、**画外标题/文案加强但不捏造**；列修改范围、是否需新图/贴字及剧透影响供选择。不要擅自把后续重大结论塞到已完成页，不把角色后来的自述改成确定真相。

## 5. 从成页到推广交接

1. 只有文字需求则止步文本。用户自行出图时交可复制的逐页提示词、实际图片数、角色参考清单；只有明确授权本批并满足费用/数量边界才调用付费生成，绝不默认发图或发布。
2. 对用户提供的乱序成图/分卷，原样留源，先核每张场景、角色、格序及相同人物是否一致，再映射页码；定妆、漫画页和多余/缺图分开记录。存疑或画面不匹配则列待处理、必要时问用户，不凭文件名和旧JSON坐标猜。对白靠实际说话人，旁白遵从项目样式；已授权的跨格调整须不改变含义和阅读顺序并记录。核实际脸手、阅读顺序、漏字、字形/手机尺寸；外语原文保留并用可塑形字体，翻译与语言未经验证须标待核。框外像素检查不能证明叙事或视觉审核通过。
3. 推广标题与文案按平台分别写，使用**已制作画面能兑现**的卖点和未过度剧透的问题；画内画外位置遵循创作者选择。别名可作系列展示名，但不当成已登记、可在阅读平台检索的正式书名；需真实搜书引导时核准确原著名、作者、阅读入口及版权/平台要求，不编造可搜、免费、完结或流量效果。信息未核实则标待办。
4. 交付时列页序、源图映射、缺图/角色和语言疑点、已完成检查与未检查项；打包后测试包可读，不把自动结构通过说成内容、移动端、创作者或平台验收。原始用户素材不覆盖，样稿与正式稿分开。

## 6. 最终叙事自检

- 此次是推广选段还是完整指定范围？是否按这个范围交付，而非以广告目标偷删事件？
- 能否沿“欲望→行动→阻碍→选择→后果”复述，且对应原著与当前图文？不可少的因果、关系、情绪和事件结果有没有在画内真正出现？
- 每个角色在每格知道什么、处于何处、拿着什么？推测是否被误写为事实？一次完整情绪转变是否有前因和可见反应？
- 上话未完事项是否逐条在本话继续、解决或明确暂缓？下一话不是悄悄切到别的故事？每格是否只有一个瞬间，阅读顺序是否清楚？
- 每话有实际推进和读者收获吗？末尾的问题具体、原文有依据、后续能衔接吗？有没有为了钩子提前透露或杜撰？
- 字体/图片/人脸/手/参考、版权、外语、设备可读性、搜书信息及平台要求哪些已核、哪些未核？分别如实记录。工具不替代创作或法律审查。
