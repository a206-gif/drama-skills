# 信息讲清楚，事件接得上

本页展开 CMC-17–22。信息准确、明确文字和跨话因果是硬性义务，不是可为节奏让步的口味。
推广原著不等于删掉理解所需的过程；留悬念可以，上一话正在发生的事情无交代消失不可以。
这些制作字段由 Agent 维护，不让创作者先学格式才能提出改编要求。

## 每格都回答：读者究竟看懂了什么

分镜中每格在来源、画面和提示词外，补充非空“信息”和“衔接”：

- **信息**：本格需要读者确认的具体事实、关系、变化或反应。不要只写“很紧张”“很震撼”。
- **画面**：本格必要的时间/地点、在场人物、位置朝向、视线表情、正在进行的单一动作、双手持物与关键物件状态。
  特写不需要把所有人都画进去，但要能从前后格理解其所属人物和动作。
- **衔接**：承接哪一格/上一话的什么状态，本格发生什么变化，给下格留下什么条件。
  “承上启下”“保持一致”没有具体状态，不能当成已完成。
- **提示词**：把信息落实为看得见的对象、构图和取景；重要证据需要可读文字时另设文字块，不能让出图模型乱拼。

出图后以当前分镜逐项看实际图片和排入文字。角色站位、递交、受伤、门开关、物件所属等与提示词不符，
就修图、换图或重排，不能因为文件存在就宣布信息表达正确。
只给“她震惊了”的漂亮脸部图，却没有让读者看到她看见什么或为何反应，不算交代完整。

## 文字必须具体，不能只交梗概

- **对白**：写逐字正文、说话人、对话对象。明确画内/画外及谁听得到，指代不清就写人名/物件名。
  “两人解释了一下”不能代替真正的解释台词。
- **内心**：明确属于谁，不把此人的猜测写成所有人已知的事实，也不让其他人无来源地知道。
- **旁白**：明确叙述身份，例如第三人称叙述、某角色第一人称回忆；把时间、地点和必要因果交代到足够理解。
  不为了少字删掉观众唯一能理解的说明。搜书/推广提示另外标作“推广提示”，不冒充故事旁白或角色台词。
- **拟声字**：与本格可见/已建立的声源对应，不拿无来源的拟声字制造事件。

对白/内心/旁白的身份必须**真的排入读者看见的画面**，不是只在制作字段里存在。本地排版器从当前分镜生成可见的“姓名｜对白/内心”或“旁白｜叙述身份”，框形/尾巴也不同；名签与正文一起计入字框测量。用户要求主角专属字体时，为各主角名签指定实际不同且可用的字体，正文仍以清晰易读为先；颜色与字体不能替代写出姓名和类型。详见[排版格式](layout-format.md)。

详细不是把一页塞满文字，而是重要信息不漏、对白和旁白说到位。
不设通用对白字数上限或“旁白越少越好”的门槛；篇幅不够就增格、增页或合理拆成承接的下一话。
不能偷偷缩字、删掉关键解释，或用一句“事情解决了”跳过关键交涉、动作和结果。

## 开始下一话前，先读上话实际结尾

续话必须读取上一话当前分镜，必要时看已接受的末页图片，而不是只凭会话记忆、梗概或推广标题续写。
逐项核对：

1. 上话最后在哪里、何时、谁在场、正在做什么？
2. 对话进行到哪一句、提问是否得到回答、交接是否真的完成？
3. 各人的知识、目标、伤势和物件所属是什么状态？
4. 哪些事件正在进行，哪些问题被明确保留，下一话欠什么交代？

下一话先承接当前事件，再推进新信息。时间/地点变化、倒叙或切换视角要在漫画中让读者看得出来，
不能只在制作说明里写“过了几天”。重要冲突不能在两话之间凭空解决。

## 同一份分镜里的最小交接

在第一个 `PAGE-*` 前写话号、连载关系、上话编号、入口/出口状态，以及承接/待续事件。
完整格式见 [排版格式](layout-format.md)，成对例子见 [首话](../assets/漫画分镜.md)和[续话](../assets/续话示例/漫画分镜.md)。

- 稳定 `EVT-*` ID 跟随同一件事，不随换话、分页或改写对白换名。
- 上话的每个待续事件，在下一话只能明确**继续、解决或明确暂缓**，并指向本话真实格/文字。
- “继续”和“明确暂缓”仍是未结，必须留在本话待续中；“解决”必须有过程与后果依据，不能同时还标待续。
- 新事件另建 ID，不能换个名字躲开旧事；一件事真的解决后又被重新打开，应明确新触发与关系，不能混为从未解决。
- 本篇推文停止时可以把核心答案留给原著，但仍记录未结，不假装已经解决。若之后制作续话，仍要承接这些状态。

这些记录是分镜的制作交接，不是第二份剧本。画面/对白正文仍只在格和 `TEXT-*` 中维护；
引用指向实际要画、要排的格或文字，不能只在交接表里写“已解决”而正文没有。

## 什么才算合法承接

- **继续**：林岚仍持信、陈默仍在门外索信，下一话先画清双方的问答和递交，不直接变成各自回家。
- **解决**：画清递信的接触、接过后的持有者和相应反应；不是只有“信已经归还”的制作备注。
- **明确暂缓**：画内对白/旁白明确为什么暂时不能谈、仍欠什么、下一步怎么推进；事件继续保留为未结。
  不能用万能的“以后再说”无限拖延，更不能借此跳过眼前必须完成的动作。
- **错误**：上话“对方到底是谁”还在质问，下话双方已经合作且互相信任，却没有确认身份或建立信任的过程。
- **错误**：上话还在逃命/递交/等待答案，下话只因想展示另一爽点，就把旧事当作不存在。

大谜团可以继续悬着；读者必须知道这是有意保留、人物接下来在做什么，而不是不知道作者漏了哪一段。

## 独立推文不是绕过承接的按钮

同一本书已按连载续作的内容，默认保持连续。只有创作者明确批准彼此独立的选段，才标“独立篇”，
写清依据，并且不对观众声称这是上一话的连续后续。不得擅自把续话改成独立篇来清空未结事项。

## 检查与交付

`check`/`render` 的续话输入必须带 `--previous`，机械核对相邻话号、待续 ID 全覆盖、状态与真实落点。
它只证明交接记录没有结构性丢项，不证明对应动作真的画出来、事件真的解决、旁白真的清晰。

交付前做一次逐格图文信息核对和逐事件承接自检；这是 owner 自检，不伪造独立 reviewer 结论。
任何必要信息、关键对白/旁白或正在讲的事件漏掉，都先修复，不能把不合格稿标成已完成。
范围不足、缺上话或缺原著依据时明确停在候选/待补；不能靠猜测把前后接起来。
