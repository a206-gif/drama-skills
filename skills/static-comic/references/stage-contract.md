# 静态漫画阶段契约

`static-comic` 独立拥有本项目的简报、视觉设定、漫画分镜、几何排版和发布交接。
它不是既有视频项目的新增制作形态；不改变视频镜头、生产选择器和五文档契约。小说改编默认以推广原著和准确搜书为目标，非完整漫画化。

## Rule tiers

- `structural_invariant`：本地可以证明的 ID、引用、几何、顺序或输入矛盾，工具可拒绝。
- `reviewed_invariant`：必须结合原著、分镜或实际图片引用证据判断的语义义务。
- `craft_default`：有帮助的起点，创作者可覆盖，不作为普遍质量门槛。
- `taste_option`：表现选择，不单独阻断交付。

## Rules

| ID | Tier | Knowledge |
|---|---|---|
| CMC-01 | structural_invariant | 页、格、文字 ID 在当前话中唯一；排版的页序、格序与逐格文字 ID 必须逐一匹配漫画分镜，不丢项、不重复、不跨格借用文字。文字正文只从分镜读取。 |
| CMC-02 | structural_invariant | 本地排版器只接收非重叠矩形格、页内显式安全边距和格内文字框；坐标为整数、框有正面积、文字尾端点在格内且在本气泡框外。允许的裁切焦点在 0–1 之间；可选image_rect是格内正面积整数矩形，留白区域可放文字，不越出本格。 |
| CMC-03 | structural_invariant | 分镜与格图输入使用排版文件所在目录内的相对路径；拒绝路径越界、符号链接逃逸和远程媒体。渲染使用实际的静态图片与显式字体，不静默采用占位图；输出写入新的目录，不覆盖源媒体或旧发布目录。 |
| CMC-04 | structural_invariant | 排字不改正文、不为适应框体偷偷缩字；实际字宽或字高超出框体、字体缺字、图片无法解码或多帧图片时拒绝渲染。任何一页失败不留下半批发布图。 |
| CMC-05 | reviewed_invariant | 改编守住创作者接受的因果、人物动机、关系与信息揭示边界；新增、合并、前置和删减留有来源与影响说明；只在授权范围内使用原著、格图、字体与参考。 |
| CMC-06 | reviewed_invariant | 每格只承载一个可同时观察的瞬间；跨格行动和道具状态可衔接。文字气泡对应说话人，尾巴和格子不会诱导错误阅读顺序；画面信息不能依赖声音或播放时间。 |
| CMC-07 | reviewed_invariant | 实际图的脸、服装、关键道具和地点遵守视觉设定；排版裁切与文字不能遮挡故事必需的证据、表情或动作接触点。几何检查通过不证明这一义务成立。 |
| CMC-08 | craft_default | 面向手机图文先提出 1080×1440（3:4）、统一页尺寸、从上到下且同行从左到右；每次先试少量页面，格数/大小/横竖随内容确定。所有值是可覆盖的编辑起点，不是平台官方规范或质量门槛。 |
| CMC-09 | craft_default | 先定每页的信息变化与翻页揭示，再选单格瞬间；推广模式首张展示原著卖点，中段给真实体验或小兑现，末页保留具体续读理由并承接搜书，不以完整讲完主线为默认目标。不要强制每页反转、卡在爽点前或所有页面四宫格；明确非推广任务按其目标收束。 |
| CMC-10 | craft_default | 默认逐格生成无字图片，再本地拼页并准确排字；以手机实际阅读大小检查字号、气泡顺序、裁切和封面，不用缩小字号解决对白超载。 |
| CMC-11 | taste_option | 黑白、彩色、网点、平涂、厚涂、异形分格、出框或跨页均可由创作者选择；超出本地矩形排版器能力时使用外部排版，不伪造本工具已支持。 |
| CMC-12 | reviewed_invariant | 外部生成先展示本批准确内容和参数并取得当次明确确认；不自动付费、不上传平台，不把本地图片导出称为已发布或审核通过。 |
| CMC-13 | reviewed_invariant | 推广所承诺的卖点、身份关系、事件与后续期待有原著或已接受范围内的明确依据；不虚构原著没有的情节、奖励、关系或反转来吸引搜索，不承诺未核实的答案与结局。 |
| CMC-14 | reviewed_invariant | 推广简报区分已展示、保留与禁止剧透，并说明具体停止位置和续读理由；最终内容不泄露已接受边界内的核心答案，也不通过删除必要因果来制造假悬念。 |
| CMC-15 | reviewed_invariant | 搜书信息使用经确认的准确原著名，区分本篇标题，作者/平台不编造。按已约定画内/画外位置交付；默认可规划末页，创作者故事优先时可迁到发布文案，不强塞广告格。画内文字保留真源ID，完整交接的封面/正文/文案一致，未核实不称可发布。 |
| CMC-16 | craft_default | 小说改编默认作为原著体验的取样而非替代阅读：围绕一个有来源的主卖点选段，给予必要理解与小兑现，再留与卖点相连的原著阅读缺口。推广判断不按每格曝光、固定篇幅、虚构转化率或完整剧情覆盖评分。 |
| CMC-17 | structural_invariant | 每格具非空来源、信息、画面、衔接、提示词；对白/内心有不为“无”的说话人，对白另有明确对话对象，旁白有叙述身份。缺字段拒绝检查/渲染；非空并不证明语义合格。 |
| CMC-18 | reviewed_invariant | 画面与实际排入文字准确表达本格必要事实、关系、动作和物件状态；以本格“信息”逐项核对实际图文，不能用泛化美图、错误裁切、制作备注或提示词自称已表达。 |
| CMC-19 | reviewed_invariant | 对白写完整实际台词，内心归属与旁白身份明确，读者能分辨谁对谁说、谁知道什么、为何发生；必要时间/地点/动机/解释给到足够细致，不以梗概代替对话，不为短快删掉理解所需信息。 |
| CMC-20 | structural_invariant | 分镜话头记录话号、连载关系、入口/出口及承接/待续事件。续话显式提供实际上话分镜，核对逐话编号、上话待续 ID 全覆盖及本话真实格/文字引用；继续/明确暂缓仍待续，解决不同时待续；首话/独立篇不静默忽略传入上话。 |
| CMC-21 | reviewed_invariant | 先读实际上一话末尾，下一话逐件继续、画清解决或在漫画中明确有依据地暂缓；时间地点、正在进行的动作/对话/追问、人物认知关系和物件状态不无交代跳过。交接状态需对应可见图文与原著因果，不能改名、虚标解决或擅自重置独立篇清空事件。 |
| CMC-22 | craft_default | 用增格、增页、适当转场与必要旁白容纳细致内容，去掉冗余但不删必要信息；无固定总页数、对白字数或旁白密度门槛。营销节奏、留悬念与版式偏好不能覆盖 CMC-18/19/21。 |
| CMC-23 | structural_invariant | render按显式lettering策略从同一分镜读正文；embedded不画身份标签、专属字体用于该角色全部对白/内心，labelled兼容旧名签。按实际样式/描边安全区测字/缺字/溢出，不暗缩字；透明底真实alpha混合，字保持不透明。breaks只引用正文内递增合法字符断点，不复制正文。 |
| CMC-24 | reviewed_invariant | 主角专属字体/字色/框形/位置与尾巴协同辨识，实际使用约定字体而非仅改元数据。是否画姓名/类型标签按创作者的呈现选择，不能把“不必标签”当成“说话归属可以不清”；透明度/实际字形/手机阅读仍须核对。 |


| CMC-25 | craft_default | 普通叙事一页多镜，单镜独幅/大幅通常强调重要转折；格数、大小、横竖和组合不固定。单格素材不自动等于发布页；裁取反应镜不伪造新动作，完整文字与必要信息优先于模板。 |
| CMC-26 | craft_default | 每轮结束给实际可执行的下一步选项、推荐与前置/费用边界；同轮把可复用制作优化回写所属skill工作流/参考，区分适用范围、实测与待验证，不让项目记忆取代技能沉淀。用户明确的协作约定按其要求执行。 |
| CMC-27 | structural_invariant | preview显式选择存在且不重复的页，保持原阅读顺序；先查全话结构与实际上话，再查所选媒体。输出标局部试排，不称全话齐图；正式render保持全话媒体要求，所选批次失败不留半批、不覆盖旧输出。 |

| CMC-28 | craft_default | 画面优先的图内贴字可用轻半透明气泡、专属全正文字体与颜色/框形辨识，不另开白带或强画名字。先核原文对白/内心/叙述，不为讲解硬加旁白；必要信息保留且有来源，推广可按要求移画外。 |

| CMC-29 | taste_option | 参考式轻椭圆对白/矩形内心叙述、浅深同色系、细分隔或满幅可按创作者选择；只借视觉语法不复制剧情/固定格数。分隔与框边看实际输出，椭圆/描边重测字框，不以像素公式代替脸手/阅读自查。 |

## Boundary and evidence

- 书名、作者、阅读平台、原著卖点与停止位置记录在已有简报中；画内搜书正文只在分镜 `TEXT-*` 中，版式继续只引用 ID，不另建营销配置或 CTA 正文副本。
- 几何工具不会验证原著真实性、平台检索结果、剧透范围或营销转化；没有实际核验/数据时保持待办，不声称已验证。
- `check` 默认只证明结构、顺序、几何与声明的相邻话交接覆盖；续话必须 `--previous` 指向实际上话分镜，不递归验证整条连载。`--media` 再检查文件就位，仍不判断图片内容。
- 字段与事件 ID 存在不能证明信息充分、事件真的解决或延期有理。详见[信息与连续性](information-and-continuity.md)；语义自检失败先修复，不能将结构通过标成图文叙事通过。
- `preview`同样执行全话结构/相邻检查，只核所选页媒体并解码；结果区分selected_media_checked与episode_media_checked，不能当全话发布证明。
- `render` 增加图片解码与所选lettering策略的字形/宽高检查；embedded不画身份标签，labelled才测绘名签。它不判定字体授权、不验证平台账号可用功能、官方尺寸或图片数量上限。
- 创作自检引用当前分镜和实际导出图片；没有独立 reviewer 时不生成独立审查 verdict。
- 默认的 48px 页边距、40px 字号是模板的可改选择；写入版式后，工具只按该版式核算，绝不当成通用平台安全区。
