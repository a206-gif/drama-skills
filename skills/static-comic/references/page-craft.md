# 漫画页叙事

本页展开 CMC-05–11、CMC-13–22 与 CMC-25；推广见[小说推文做法](novel-promotion.md)，详细图文与跨话硬要求见[信息与连续性](information-and-continuity.md)。
事实准确、文字明确与事件连续是 `reviewed_invariant`，不能让位于节奏；具体格数/表现手法仍为 `craft_default`/`taste_option`。

## 从小说到本话

小说推广先问“原著为什么值得读、这篇展示什么体验、看完为什么还想搜原著”，而不是“一章有多少字”或“能画完整多少剧情”。
本篇的小变化服务该卖点；创作者明确选择完整漫画化时再以其话级目标组织。
保留使选择成立的动机和因果，把可画的叙述转成行动，把不可外显但必要的思想用足够明确的思考框表达，不先以字数删减。
环境描写变成建立格，背景资料按理解需要给足；旁白以清楚的叙述身份详细交代必要信息，不拿大段堆字或过度短句代替改编。

对前置高潮写清：读者先获得了什么、仍不知道什么、原本的铺垫在哪页补足。
不能为封面改坏角色立场，或让悬念答案已经在前一格背景里泄漏。

## 先页后格

每页先用一句话描述“进入时的认知→出去时的认知”。
把决定、证据、反应或处境变化分配到页面，翻页后再放必须惊讶才成立的局部答案。推广模式将核心谜底与大结局按简报保留给原著，末页承接准确搜书提示；不为了留悬念抹掉必要理解或所有小兑现。
如果同页已经露出答案，不能靠要求读者先看上格维持悬念。

一格是一次看见，不是一个持续镜头。例：

- 不好：她推开门、跑进屋、打开箱子、发现空了。
- 可拆：门缝与她的手；她掀开箱盖；空箱特写；她看向窗外留下的脚印。

不是所有动作都要拆成四格。读者能从相邻状态可靠推断的常规走动可以简化；关键交接、对质、误会、承诺与证据变化要画清，不在两话之间无交代省掉。

每格“信息”写读者应知道的事实，“衔接”写从前格/上话什么状态变化到这里、下格接什么。
一格不够讲清就拆格/增页，不把复杂对话压成“他们商量好了”，也不强制一个格只能有一句短台词。

## 页内阅读路径

默认上到下、同行左到右。用行带组织阅读，避免两个竖向格同时可被理解成第二格。
格序和文字序在分镜与版式里一致；版式列表就是阅读顺序，不靠生成模型自己猜。
如需右到左或自由跨格路径，先明确接受新阅读约定并人工查路，不把左到右模板原封套用。

- 对话页可用几格稳定节奏，再用反应格改变关系。
- 证据揭示给足画面面积，不把关键信息挤进手机上不可读的小角。
- 冲击大格需要与前面的蓄力形成对比；所有格都大就没有强调。
- 无字格可以承担迟疑、羞耻、恐惧或关系距离，不强制给它配旁白。
- 普通叙事以一页多镜推进；单镜独幅/大幅通常用于重要转折与情绪落点，但不是每个转折必须独幅。格数、大小、横竖与组合跟随信息负担，不定固定格数或等大网格。

## 人物与状态连续性

视觉设定只锁跨格应不变的身份、发型、服装、道具材质等；受伤、湿衣、道具持有者等写明开始和结束范围。
每格具体写可见人物、双手、关键物件与相互方位。上一格还在左手的信不能无交代出现在另一个人手上。
构图角度可以改变，但门、桌、窗的空间关系不能随格漂移。
续话先读上话实际结尾与待续，不能还在递信/追问就跳成已交完/已互信。需要延后时，在漫画中说明原因与未结，
用稳定事件 ID 保留到下话；时间、地点和视角切换也要有可读依据，不只在制作备注解释。

同一格只需本格必要的事实与参考，不把整本设定贴进每条提示词。参考图只控制它被指定的身份、服装、地点或画风，
不能让一张地点参考把所有近景都拉成远景。

## 无字出图与可编辑文字

将角色和表情安排在气泡预留区外；提示词直接写取景范围、主体位置和空白方向，避免“高级漫画感”等泛词代替构图。
不在提示词里要求生成正确的整段中文。对白、思考、旁白、拟声字与搜书提示由分镜的 `TEXT-*` 块保管，排版只取 ID。
画内搜书提示采用时独立于人物台词；用户要求故事优先可改画外文案，不为广告另造剧情格。准确书名与位置策略需明确。

气泡按阅读顺序出现。对话尾巴指向嘴或清楚的说话人区域；思考框不要指给听者；旁白框不画说话尾巴。
文字框不能盖住眼睛、掌心里的证据或决定行动是否成立的接触点。超载时增格、增页或改版式；正文可去冗余但不能省掉必要解释/承接，不能偷偷缩字。

## 画面与文字的两次自检

1. 只看图：人物在做什么、证据是什么、前后状态是否连得上？
2. 只看字与气泡位置：谁对谁说、旁白身份、先后和必要解释是否明确？
3. 合看实际图文：逐项满足每格“信息”了吗？上话正在进行的每件事在本话哪里继续/解决/明确暂缓，未结是否保留？

最后把整页缩到手机实际近似显示宽度阅读，而非只在桌面放大看。
工具只核算框体和字宽，读不懂故事，也不知道一张图片上的脸是否被气泡挡住。

## 素材不是页面，图文预算先于模板

这是CMC-25的`craft_default`，不覆盖必要信息与文字清晰的硬要求。

- 先问本页进入/离开时的认知差，再分配镜头面积；不要按生成图片数量决定发布页数。独幅强调转折，与前后普通多镜形成对比，而不是所有画都各占一页。
- 一格既有重要表情又有长对白时，可在格内预留独立文字带/侧栏，用`image_rect`控制真正图片区；文字仍是原格的TEXT，不假造一格“白底对白”来凑镜头。
- 一页承载不了完整文字与关键脸手时可以拆页：转折页聚焦变化，下一页用建立镜/对话与有功能的反应镜接续。不是固定两页公式，也不能借拆页跳过正在谈的事。
- 已有画面可裁成反应/细节镜头，但只表达原图同一时刻的信息；不把裁切当作新的动作、证据或表情。裁后需看主体和分辨率，记原图/坐标/用途。
- 修改分页要同步页/格/TEXT编号、事件引用、排版和派生快照；原文内容不因挪版而被改写。已有图文件名可保留，靠明确绑定追溯，勿无必要重生图。

## 真图复核的小修次序

1. 先保护眼睛、手与接触点，调整图片区/格形/分页，不先缩字。
2. 再让正文与可选名签自然断行；embedded不画姓名，靠气泡/字色/全正文字体/位置辨识，不为标签空一行。必要时用源字符断点分完整短语，制作解释放备注。
3. 气泡尾巴指向清楚的说话人附近，不把长尖尾穿过头脸、眼睛或关键手势；思考点尾不指给听者。
4. 搜书提示在独立文字区，书名/作者读清；调框宽可避免下一句开头孤留上一行，不篡改正文来凑版。
5. 看实际导出及手机近似缩览，再将可复用的修法回写本页或[制作技巧](production-learning.md)。字框通过不等于无遮挡或手机验收。

## 画面内贴字而非为字另造版面

`craft_default`：先看被指定旧贴字成品，把文本压在自然低细节区域；名字/类别标签、独立白带与实底框不是漫画必备。采用embedded时字色/专属全正文字体、泡形/尾巴协同，原图满格，避脸与关键接触点；气泡更透明也不能靠字叠在眼睛/证据上“省空间”。

半透明底与字分开处理：先实际alpha合成底，正文保持不透明并以适当描边保对比。原文已有内心可承载人物认知；环境已画出来不重讲，没来源不为“旁白显得完整”添解释。源中合法有旁白不等于每页必放旁白。

用完整台词先测字，再把一句拆成有顺序的多个气泡或用源字符断点修短语；不删词、不暗缩字，也不把新增白带算“更漫画化”。本地机械测量只能证明字能放下，最终必须实际看图与缩览。
