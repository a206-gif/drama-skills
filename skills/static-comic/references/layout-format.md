# 分镜、相邻话交接与几何排版格式

本地工具落实 CMC-01–04、CMC-17、CMC-20、CMC-23 与 CMC-27 的结构部分，只做声明、引用、相邻话对账、几何、图片拼排和字框测量，不理解或创作剧情。
它支持同尺寸画布、矩形行带、同行左到右的阅读顺序；异形格、出框、右到左、跨页、复杂竖排和任意图层排版请用外部工具。

## 漫画分镜是正文真源

参考[合成首话](../assets/漫画分镜.md)和[配对续话](../assets/续话示例/漫画分镜.md)。结构如下：

- 一级标题写话名；第一个页前有下节的话头与交接。二级标题只能是 `PAGE-001` 这样的页 ID。
- 每页用 `- 本页职责：...` 写信息变化；三级标题为该页的 `PANEL-001-01` 等格 ID。
- 每格必须有非空 `- 来源：...`、`- 信息：...`、`- 画面：...`、`- 衔接：...`、`- 提示词：...`，可增加视觉依据等说明。
  信息写读者应理解的事实，衔接写前后具体状态，不能只用空泛标签；非空检查不能证明内容合格。
- 四级标题为 `TEXT-001-01` 等文字 ID，跟在所属格内；编号在一话内唯一。
- 每块文字有 `- 类型：dialogue/thought/narration/sfx` 中的一项和非空 `- 正文：...`。
  `dialogue`、`thought` 必须有明确且不为 `无` 的 `- 说话人：...`，可注明“画外”。
  `dialogue` 还必须有 `- 对话对象：...`，不能写 `无`；`narration` 必须有 `- 叙述身份：...`，例如第三人称、某角色回忆或推广提示，不能写 `无`。
- 采用画内搜书提示时仍用独立`TEXT-*`、类型`narration`、说话人`无`、明确推广身份；若创作者选画外文案，则不造推广格/旁白块，策略在简报记录。
- 正文是单行纯文本，不放 Markdown 标记、HTML 或占位符；换行由排版器按字体测量后加入。
  字段使用中文冒号，值中可含冒号，工具只切第一个冒号。无字格不用硬造文字，但仍写信息与衔接。
- 页/格/文字标题不带别名或装饰；编号不必连续，列表顺序才是阅读顺序。话号另外按连续要求检查。
- 说明文字可放首个页前；正文内额外二/三/四级标题会报错，避免静默漏掉不规范的格。

## 话头与事件交接

以下是**续话**格式示意，所有格/文字引用必须是该话真正存在的 ID：

```markdown
- 本话编号：CH002
- 连载关系：续话
- 上话编号：CH001
- 入口状态：承接上话具体时间地点、正在进行的行动、持物与认知状态。
- 出口状态：本话末尾仍在进行什么、谁持有什么、哪些问题尚未交代。
- 承接事件：EVT-LETTER-RETURN | 解决 | PANEL-002-01、PANEL-002-02 | 画清双方接触、松手和归还结果。
- 承接事件：EVT-MISSING-RETURN | 继续 | TEXT-002-02、TEXT-003-02 | 继续询问，失踪经过尚未得到回答。
- 待续事件：EVT-MISSING-RETURN | TEXT-003-02 | 对话停在当面追问，下一话必须接回答或有依据的继续/暂缓。
```

- **必填单值字段**：本话编号、连载关系、上话编号、入口状态、出口状态，不重复、不空值。
  本话编号为 `CH001` 等 `CH` 加至少三位 ASCII 数字的正整数，续话按数值比上话加一。
- **连载关系**：`首话`、`续话` 或经创作者明确批准的 `独立篇`。首话数值必须为 1。
  首话/独立篇的上话编号写 `无`、承接事件写 `无`；独立篇额外写非空 `- 独立篇依据：...`，需真实的创作者批准记录。
  不能擅自重置首话/独立篇来清空正在推进的事；代码不验证批准记录的真实性。
- **记录字段**：“承接事件”可重复行，每行 `事件ID | 状态 | 本话落点 | 本话的处理事实`；
  “待续事件”可重复行，每行 `事件ID | 本话落点 | 出口事实与下话欠的交代`。
  每组都必须出现，没有事件写 `- 承接事件：无` / `- 待续事件：无`，不能漏写、重复“无”或与记录并存。
- **稳定事件 ID**：`EVT-` 后为大写 ASCII 字母/数字及用单个短横线连接的段；同组内不重复。
  两话中的同一个 ID 必须指同一件事，不能通过改名绕过。名称相同是否仍是同一事件要结合正文检查。
- **状态**：只接收 `继续`、`解决`、`明确暂缓`。继续/明确暂缓必须仍在本话待续中，解决不能同时待续。
  暂缓须在漫画中说明原因与未完事项；解决须有可见过程和结果，不能只在记录里宣称。
- **落点**：本话实际存在的 `PANEL-*` 或 `TEXT-*`，多个用顿号或 ASCII 逗号分隔；不能只写页号、制作备注或上话的不同落点。
  工具检查引用存在，不能证明对应图文的实际意义。
- **续话输入**：`--previous` 显式指定实际上一话的 Markdown；不自动从路径猜测、不联网、不递归寻找全连载。
  核对提供文件的话号、连续话号，以及“上话待续 ID 集合 = 本话承接 ID 集合”，缺旧事件或冒出无依据承接均拒绝。
  提供了上话却标首话/独立篇也拒绝；缺文件或把本话当上话不能继续。

旧分镜缺少上述字段时需要补齐真实来源、正文与交接，不以自动填“无”迁移来绕过信息缺失。
相邻交接的机械核对不等于全链验证；制作 CH003 时还须显式对照 CH002，不能跳着验。
详细语义义务见[信息与连续性](information-and-continuity.md)。

## 排版 JSON 只保存排版

直接复制[首话版式](../assets/page-layout.example.json)或[配对续话版式](../assets/续话示例/排版.json)，与对应分镜放同一话目录。
JSON 不写对白、提示词或交接事件副本；未知字段会拒绝，防止拼错字段静默回退。

| 层级 | 字段 | 含义 |
|---|---|---|
| 根 | `version` | 固定整数 `1` |
| 根 | `storyboard` | 相对本 JSON 的分镜 Markdown 路径 |
| 根 | `canvas` | `width`、`height`、`margin`，整数像素；可选`panel_border_width`控制格外框，默认3、0不画，0–64为本地资源范围；边距明确选择后按该值检查 |
| 根 | `pages` | 按分镜顺序的非空页列表 |
| 页 | `id`、`panels` | 页 ID 与按分镜顺序排列的格列表 |
| 格 | `id`、`rect`、`image`、`texts` | 格 ID、页坐标 `[x,y,w,h]`、格图相对路径、文字列表 |
| 格 | `focus` | 可选 `[横向,纵向]` 裁切焦点，均在 0–1，默认 `[0.5,0.5]` |
| 格 | `image_rect` | 可选格内 `[x,y,w,h]` 图片窗口，正面积整数矩形、不得越格；不写时等比铺满整格，窗口外为白底，可留文字带/侧栏 |
| 文字 | `id`、`rect`、`font_size` | 分镜文字 ID、格内坐标 `[x,y,w,h]`、整数字号 |
| 文字 | `padding` | 可选整数内边距，默认 `20`；不能大到吃完文字框 |
| 文字 | `tail` | 可选格内坐标 `[x,y]`；仅对话/思考可用，在本框外、格内 |

格子不可相交；同行顶边相同且左到右，下一行顶边不高于上一行底边。同格文字框不可相交。
框与尾巴完整留在所属格内；视觉上的说话人、遮挡和尾巴路径仍需核对。
裁切焦点作用于image_rect窗口（省略时为整格），只改变等比铺满后的取景，不拉伸原图。文字坐标仍相对整格，允许覆盖图片区但需人工检查遮挡；工具不把留白带另算故事格。画布单边不超过 8192px、单页及单格图不超过 3200 万像素，是本地资源限制而非平台限制。

分镜与格图路径使用 `/` 分隔，相对于排版 JSON；不接收绝对路径、`..`、反斜线、远程 URL 或逃出目录的符号链接。
命令行字体与上话 Markdown 可显式位于项目外，不复制进发布目录，不被当成格图路径或远程链接。

## 局部实图试排

整话未齐图时可明确选已齐图的页：

```bash
python3 {技能目录}/scripts/comic_tool.py preview 第002话/排版.json \
  --previous 第001话/漫画分镜.md --page PAGE-002 --page PAGE-004 \
  --font <实际中文字体路径> --out 第002话/局部试排-v1 --format png
```

- 必须显式选择现存页ID，不可为空/重复；输出保持原分镜页序，不因参数顺序反转阅读。
- 仍先验证全话结构、几何和实际上话/事件交接，只检查/解码所选页媒体及其字形/字框；未选页缺图不阻局部试排，但结构或交接错误仍拒绝。
- CLI与库调用都返回`preview_rendered`、`scope: selected_pages`、`selected_pages`、`episode_pages`、`selected_media_checked: true`、`episode_media_checked: false`；不可当全话齐图/内容或发布验收。
- 输出仍事务式完成，损坏/动画/缺字/超框或晚失败不留下半批，不能覆盖旧目录。全话`render`仍要求所有媒体，不通过新造首话/独立篇或占位图绕过。
- 库使用`preview_plan(load_project(...), [页ID...])`后交`render`，范围标记随计划保留；不要手工删范围字段伪装成全话。

## 命令与依赖

```bash
python3 {技能目录}/scripts/comic_tool.py check 第001话/排版.json
python3 {技能目录}/scripts/comic_tool.py check 第001话/排版.json --media
python3 {技能目录}/scripts/comic_tool.py check 第002话/排版.json --previous 第001话/漫画分镜.md
python3 {技能目录}/scripts/comic_tool.py render 第002话/排版.json \
  --previous 第001话/漫画分镜.md --font <实际中文字体路径> --out 第002话/发布-v1 --format jpg
```

- Python 3.9+；`check`、局部选择的结构检查和安装自测仅标准库；渲染需 `Pillow>=10.4,<12`。
- 裸 `check` 允许图片未生成；`--media` 只多查文件存在、非空和扩展名，不解码/判断图片内容。续话在两种模式下都要求上话输入。
- `render` 先做同样的结构/交接检查，再解码 PNG/JPG/JPEG/WebP，按 EXIF 转正、等比铺满和焦点裁切；透明图合成白底。
  多帧 PNG/WebP 拒绝。输出为不携带源 EXIF 的 RGB 静态 PNG/JPG。
- 所有文字从当前 Markdown 读取。字体常见缺字会检测，仍须预览核对字形、标点、授权和手机可读性。
- 中文横排按实测宽度断行，避开常见行首闭标点/行尾开标点。复杂塑形、彩色 emoji 和连字用人工检查或外部排版。
- 旧默认对话圆角框/三角尾、思考椭圆/点尾、旁白矩形、拟声描边；embedded可按类型/人物选择形状。椭圆对白的尾巴也从实际椭圆边缘起，不从矩形角起。
- 不配置`lettering`时维持旧`labelled`：可见“姓名｜对白/内心”“旁白｜身份”，来源仍是Markdown，名签计入字形/宽高；`--speaker-font`仅换名签，正文保持`--font`。这是兼容行为，不是所有漫画必须画姓名。
- `lettering.mode: embedded`：不画姓名/类别标签，`--speaker-font`用于该角色完整对白/内心正文；旁白/未配置人物用`--font`。隐藏的姓名不要求出现在字体字库中，实际正文仍查缺字/溢出。角色按完整字段精确匹配，不猜昵称。
- embedded的半透明气泡先画RGBA再实际叠到图片上；`bubble_opacity`仅控制气泡底/轮廓，字本身100%不透明，旧默认2px白描边；可按类型改细描边/深描边或0不描边。无底内心可用`none`；可显式左对齐矩形内心/叙述，`oval`左对齐也从椭圆安全内区开始，其他默认居中。按形状、实际描边量安全区。不可仅修改PNG元数据假装透明。
- 标签模式默认中文，纯英文可`--label-language en`；embedded不画标签，参数不改正文语言。输出明确`lettering_mode`与`visible_labels:false`，不表示源身份字段可以省掉。

```bash
python3 {技能目录}/scripts/comic_tool.py render 项目/第002话/排版.json \
  --previous 项目/第001话/漫画分镜.md --font <清晰正文字体.otf> \
  --speaker-font '角色甲=/字体/楷体.ttf' --speaker-font '角色乙=/字体/粗宋体.otf' \
  --out 项目/第002话/发布-v2 --format png
```

上面是合成角色示意；实际故事按其真实分镜姓名精确指定。主角专属字体也必须看真实字形、授权及手机近似缩览，不把命令行参数存在当作识别已通过。
- 图片全批成功后才把新目录置为输出；目标目录必须不存在，失败不留部分发布图，旧图不改动。
- 文件名取页 ID，如 `PAGE-001.png`；只导出正文页，不自动造封面/PDF/视频/上传任务。

## 报错如何修

JSON 输出 `status: valid/rendered/preview_rendered/invalid`；失败退出码 1。检查摘要含本话号、实际核对的上话号或 `null`，以及待续 ID，
只表示结构/相邻记录核对，不是图文语义或原著推广效果通过。

- 缺上话、跳话、事件漏接：先读实际上话结尾，补本话真正的承接图文与交接记录，不能仅篡改 ID/状态以“刷绿”。
- 缺信息/衔接、对白对象或叙述身份：补实际的明确表述，不能填空泛占位词。
- ID、顺序、空字段：修分镜/版式对应，不能删必要文字消除引用错误。
- 格/文字相交或超界：修改版式；自由布局改用外部工具，不谎称已支持。
- 缺图、空图、损坏、动画图：提供真正的静态格图；占位图片不算成品。
- 字体缺失/缺字：指定支持正文的字体，不静默回退；使用授权另行核验。
- 文字放不下：增框、增格、增页；改写只可去冗余，不能省掉理解和承接所需的字，不自动缩字。
- 发布目录已存在：选择 `发布-v2` 等新目录，不覆盖旧版或指回源文件。

检查/渲染不会证明改编授权、图文准确、事件实际完成、整链连续、平台预览或发布成功。

## 可选画内贴字配置

根对象允许可选`lettering`；v1没有此对象仍按旧模式。例（人物名只用于样式映射，不画入图内）：

```json
"lettering": {
  "mode": "embedded",
  "bubble_opacity": 88,
  "kinds": {
    "dialogue": {"shape": "oval", "stroke_width": 1, "stroke_color": "#263238", "outline_color": "#FFFFFF"},
    "thought": {"shape": "rect", "align": "left", "stroke_width": 0, "outline_color": "#FFFFFF"},
    "narration": {"shape": "rect", "align": "left", "color": "#20282C", "stroke_width": 0}
  },
  "speakers": {
    "角色甲": {"color": "#843B60", "dialogue_color": "#F2CDD9"},
    "角色乙": {"color": "#284F70", "dialogue_color": "#C4DEF1"}
  }
}
```

- `mode`必填且只能`embedded`或`labelled`；labelled不接受新样式参数，避免静默忽略。以上数值是例子，不是质量配额。
- `bubble_opacity`为0–255整数，不接受bool，默认96。0是底/边完全透明，255实底；文字始终不透明。更透明不代表在任何背景上都更清晰，须看实际字形/描边与关键画面。
- `speakers`可省略；键为源中完整姓名，值只允许`color`、`dialogue_color`、`thought_color`（#RRGGBB），以及`dialogue_shape`/`thought_shape`（round/oval/rect/none）。人物专用类型字色优先于人物基础色，再优先于类型色。人物形状优先于类型形状。无配置按源类型选圆角对白、椭圆内心、矩形叙述/无框音效；不允许把正文或提示词放进样式。
- `kinds`可省略；键只用`dialogue/thought/narration/sfx`，每种可选`shape`（同上）、`align`（left/center）、`color`/`stroke_color`/`outline_color`（#RRGGBB）及`stroke_width`（0–8整数，本地资源限制，不是审美门槛）。`stroke_width: 0`不画字边，实际描边宽度计入安全区；`outline_color`只改气泡边色，其alpha仍随底不透明度，不改字透明度。类型默认形状和描边与旧embedded兼容；显式align缺省时，无框字左对齐、其他居中。未知键/错误类型拒绝，不复制正文。
- `canvas.margin`只规定格的安全边，不自动重排格子；格缝来自`rect`间隔。选择满幅细缝时显式设margin/格框，并改真实格坐标；`panel_border_width: 0`不改变可选`image_rect`的窗口框。不要把示例像素或参考三等格当通用公式，仍核真实图和阅读路径。
- TEXT布局允许可选`breaks: [5, 9]`，表示在**源正文**第5、9个Unicode字符之后手工换行；不复制正文。列表必须递增、不重复、在正文内部，不以闭标点开行/开括号结行；片段仍按实际宽度继续折行，字符/顺序不变。改源后重看断点与画面，不能拿有效索引代替自然断句自查。
- 使用`--speaker-font`为角色甲/乙传入实际不同字体；embedded时作用于全文，缺文件/缺正文字形拒绝。气泡/字色/位置与字体共同辨识，不能用透明度掩盖字看不清或谁在说不明。
