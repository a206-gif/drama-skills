# 抖音与小红书的小说推文图文交接

本页是 CMC-08–22 的交接做法，不是平台实时规则表。目标是让读者看到原著吸引力、准确搜到并阅读原著，
不是把小说完整讲完，也不是只追求漫画浏览量。选段与停止位置见 [小说推文做法](novel-promotion.md)。
页面尺寸、推广/引导方式、图片数量、封面裁切和标识要求可能变化，以发布时该账号实际界面与有效规则为准；
没有核验时不能写“官方要求”“允许这样引导”“保证通过”。图文发布平台不等于原著阅读平台，不能自行添加阅读入口。

## 建议的共用母版

以下全部是可覆盖的 `craft_default`，适用于本次“一页多格、手机翻阅”的推广目标：

| 选择 | 起点 | 用意 |
|---|---|---|
| 页面 | 1080×1440，3:4 竖版 | 保留多格空间，先做一套两边可预览的母版 |
| 尺寸一致 | 同一篇所有发布图相同画幅 | 避免阅读中频繁变换版式比例 |
| 页边留白 | 模板四边 48px | 给边框和内容留余量；不是平台通用安全区 |
| 基础文字 | 模板 40px，明确中文字体 | 作为手机缩放测试起点；包括搜书提示在内均需实看 |
| 页内负担 | 通常约 3–5 格 | 优先卖点、表情、证据和对白可读性；格数由情节决定 |
| 输出 | PNG 或高质量 RGB JPG | 是独立静态图片，不是 MP4；以实际上传压缩效果复查 |

如果任一平台实际预览裁掉必要内容，保留原始格图与文字，另建该平台的版式；
不能为了“一套通用”硬裁掉卖点、剧情线索或原著名。两边可共享故事与格图，不必强行共享同一裁切。

## 首张、停点与搜书承接

首张可直接是有入口的漫画第一页，也可以另做封面，由创作者选择（`taste_option`）。
优先让受众看见本篇的原著卖点，不用通用美女图、无关猎奇或原著没有的关系骗点开；标题必须由当前内容支持。
单独封面与正文分开编号，并在发布文案列出顺序。在列表缩略图、封面和正文视图分别预览。

中间给足理解和一种真实阅读体验；最后保留与卖点相连的具体问题，不完整揭露核心答案。
推广模式默认在末页以独立 `TEXT-*` 旁白块给出准确书名和搜索提示，可在简报记录其他合规放置方案。
先在出图提示词预留位置，再排入文字；提示要看得清，但不能盖住证据或用大段广告替代故事。
本篇标题、原著名各负其责，“未完待续”本身不是搜书信息。

## 发布文案与上传顺序

完整推广交接需要《发布文案.md》；只有文本/排版的请求，不为补齐交接自动扩展任务。
文案从同一简报与当前分镜取事实，记录：

- 推广目标、原著准确书名、作者（已知时）、搜索词与可选已核实阅读平台。未确认就标待办，不能把本篇标题当书名。
- 本篇标题、简介、题材标签，以及每个承诺对应的原著卖点；禁止未核实的“免费、完结、独家、排名”等宣传声明。
- 剧透边界、停止位置、已给到的小兑现与留下的续读理由；不要在简介或封面补泄漏漫画刻意保留的答案。
- 画内搜书提示的页/文字块，准确正文以分镜为准；原著名与搜索词在所有材料中一致，不能只在简介里写而漏掉承诺的画内提示。
- 封面、编号图片顺序，以及原著/改编/图像/字体的授权与署名依据；不编造推广改编权利。
- 当次平台功能和规则核验、推广与 AI 标识/内容提示、实际预览结论；未知写待核验，不用错字、暗号或虚假说明绕规则。

## 发布前人工检查

结构检查或导出成功不能代替以下 `reviewed_invariant` 的实际观察：

1. 只看首张和末页：能否说明这本原著的吸引力、想继续读的原因，以及准确该搜什么？
2. 在手机接近实际显示大小逐页读：不放大能否认字？搜书提示实际进图了吗？气泡、证据和关键动作是否被遮挡？
3. 用原著核对身份、关系、卖点、对白含义与剧透边界；没有为了卡点删坏因果或把未核实后续说成事实。
4. 在两边各自实际上传预览中检查封面裁切、整图比例、顺序、压缩清晰度和界面遮挡，特别是原著名。
5. 核验当前账号的图片/推广限制，以及授权、署名、AI/推广标识和内容提示。书籍搜索或阅读入口未核实就明确待完成。
6. 由创作者自己决定是否发布。本技能不登录、不上传，不承诺审核、流量、搜索率或阅读转化；数据必须来自后续授权观察。

没有实际预览或必要核验时，交接状态只能是“本地推广图文素材已导出，发布前检查待完成”。

## 信息与连载不能被发布节奏挤掉

逐格实际图文要准确、文字清晰详细、对白/旁白身份明确；手机显示太密时增页或重排，不缩字/删关键解释。
当次平台数量限制若容不下，先核实规则，再在合理停点拆成连续话；不能为了塞进一帖把进行中的事跳掉。
续话先核对上话实际结尾及全部待续事件，封面/CTA/简介不算剧情交代，不能拿“去看原著”冒充本话已解决。
本次推文可以保留原著问题并停止制作；若以后继续，仍从分镜记录的出口与未结状态承接。
