# 小说推文漫画：让读者想去读原著

本页展开 CMC-13–16。小说改编的默认目标是**展示原著吸引力，促使读者准确搜索并阅读原著**，不是完整漫画化或替代原著。
“所有创作服务推广”不等于每格都放广告；画风、对白、格子、停点和文案共同服务同一个读书理由。
原创故事或创作者明确选择完整改编时，按其已接受目标处理，不强套推广。

## 先在创作简报里定五件事

1. **推广哪本书**：准确作品名、作者（已知时）、原文文件及可用范围、权利依据。文件名中的渠道后缀不当成书名；
   本篇漫画标题不能代替原著名。若要点名阅读平台，另核对该书确实可在该平台找到，不把图文发布平台误当原著阅读平台。
2. **凭什么吸引人**：写一个本篇主卖点和原著位置，例如关系张力、身份反差、规则困境、解谜、幽默或逆袭回报。
   不因题材标签就凭空添加羞辱、出轨、死亡或系统奖励。结论只覆盖实际读过的范围。
3. **给读者尝到什么**：本篇展示哪一个真实情绪体验或小兑现，让读者知道原著好看在哪里，而不是只有悬念和“去搜书”。
4. **为什么还要读原著**：写出已展示、主动保留、绝不泄露的内容；剩余问题应与卖点直接相连，
   能在原著中继续追踪。不能承诺未核实的答案、章节号、后续关系或结局。
5. **在哪里停、怎么找到书**：具体到来源位置与停止理由，确认末页搜索提示的完整字样。
   书名未确认时可以做候选分镜，但搜书卡和发布文案不能标为可发布。

这些选择写入已有《创作简报.md》，不另建推广数据库或第二份对白文件。
原著推广仍须准确、细致且连续，详见[信息与连续性](information-and-continuity.md)；悬念/短快不能盖过必要过程与明确文字。
授权、正文真实性、搜索信息、剧透边界，以及信息准确、文字明确和事件连续属于 `reviewed_invariant`；具体节奏与表现手法才属于 `craft_default`/`taste_option`。

## 选段：不是从第一章照着画

初篇优先找用较少背景就能看懂、又能代表原著核心体验的一段；续话必须先接上正在进行的事件，不能靠重新选高光跳过去。需要时给出少量候选，比较：

| 问题 | 要说明的证据 |
|---|---|
| 首张为什么值得停下来看？ | 原著中的具体处境、反差或问题，而非空泛标题 |
| 不熟悉原著能否理解？ | 必要的人物关系、行动动机与规则在何处交代 |
| 中间实际给到了什么？ | 一次真实反击、关系拉扯、发现、笑点或别的阅读收益 |
| 看完为什么会找这本书？ | 有具体对象且未被本篇解释完的原著问题或持续体验 |
| 是否泄露太多或说错？ | 停止位置、保留答案、前置/压缩的依据和影响 |

不要为了逐章覆盖而堆砌无关设定和次要支线；但理解必需的背景、对白、旁白、动作过程和跨话交代不能省，篇幅不足增格增页；也不要只拼高光，把因果、动机或关系改成原著没有的样子。
画面美化、分格和叙述视角可以变化，读者据此对原著形成的关键期待不能被误导。

## 从首张到末页

- **首张**：给出本篇主卖点的可见处境，文案具体且有原著依据；不花多页介绍世界观才开始故事。
- **中段**：用必要铺垫、角色选择和至少能被感知的阅读收益展示原著体验。“小兑现”不是强制打脸、反转或结案。
- **停点**：在选择、后果、新信息或关系变化将继续推进处停下。可以兑现一个局部问题再保留更大的问题；
  不要求每次都卡在爽点前，更不把缺掉因果造成的困惑当悬念。核心谜底和大结局按已接受剧透边界保留。
- **末页承接**：让仍想知道后续的人知道搜什么。默认在末页安排独立、清楚、不挡表情/证据的搜书文字块；
  其作用是连接眼前问题与原著，不是长篇广告，也不代表上一话的事件已经解决。其他放置方式由创作者与当次平台规则决定，并在简报说明。

每页/格可以承担卖点、理解铺垫、真实体验、续读缺口或搜索承接。无助于这些职责的内容考虑删改；
不设置强制页数、每页反转次数或每格书名曝光配额。

## 搜书提示如何落到漫画中

- 对外用准确原著名，必要时加作者消歧；需要点名阅读平台时先确认平台与作品匹配，不自行编造。
- 若采用画内搜书，提示正文写在《漫画分镜.md》的独立 `TEXT-*` 中，类型用 `narration`，说话人用 `无`，叙述身份明确为“推广提示，不属于故事叙述”；
  它是推广提示，不伪装成角色说出的台词。版式只引用该 ID，在出图提示词中预留对应区域。
- 默认在末格或末页的已规划区域排字；不要覆盖关键线索。标题、书名和提示都由后期准确排入，不让出图模型拼汉字。
- 示例结构是“与本篇相关的续读问题 + 搜索原著《准确书名》”，不是必须照抄的口号。
  作者、平台、免费/付费、完结/连载、独家、排名、读者评价等信息，没有依据就不写。
- 《发布文案.md》使用同一原著名与搜索词，另外记录封面/简介/标签/上传顺序；不能只在简介里留搜书信息却漏掉已承诺的画内提示。
- 按发布时有效规则核对推广标识与引导方式；不保证平台允许，不用错别字、暗号或虚假说明规避规则。

完整推广交接需要《发布文案.md》；用户只要求文本分镜或拼页时，不自动扩展任务，未做的推广交接明确标待完成。

## 推广视角的最终自检

只在当前请求的交付范围内自检，用户没点名时不启动独立审查或生产：

1. 是否能用原著位置说明“这本书值得看在哪里”？
2. 首张是否展示了这个卖点，且没有捏造与原著不符的身份、关系或情节？
3. 中段是否给了真实体验，而不是只引诱、不给理解和回报？
4. 末页留下的续读理由是否具体，答案/后续是已核实还是明确未知？有没有泄露核心答案？
5. 已选画内/画外策略是否真实落地？采用画内时核文字块/位置/导出；画外时核发布文案，不强塞剧情格。准确书名是否与简报一致？
6. 每格必要事实与详细台词/旁白是否在当前图文里讲清？续话是否读了实际上话结尾，每个进行中的事件都有真正的继续/解决/明确暂缓及待续？
7. 手机实际大小是否能读清搜书信息？作品、素材、推广与平台要求是否已核验或诚实标为待办？

本地结构检查只能证明文字块被引用、能排入框体，不能证明书名真实、原著忠实、读者会搜索或转化有效。
如有后续授权统计，可记录实际搜索/阅读等观察；没有数据时不编造转化率或宣称“爆款”。

## 故事优先时的画外搜书

创作者明确不想广告/讲解挡画时，搜书信息改放《发布文案.md》并记入简报，漫画只讲故事，不强制推广尾栏。画内`TEXT-*`若迁出，须从真源与几何一起移除并记录迁移，不能只在渲染时漏画已规划文字。未选择此策略时仍按既有画内计划交付。原著名/作者/入口的准确性与授权待办不因放画外而免除。
