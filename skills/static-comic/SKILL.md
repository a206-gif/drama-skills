# 原著推广型一页多格静态漫画

交付的是**可逐张翻阅的漫画图片**，不是带时长的关键帧、幻灯片视频或加配音的静态漫剧。
本技能可以独立安装；现有短剧技能只按名字可选调用，不依赖它们的文件或配置。

**小说改编的默认目标是小说推文：让读者想搜索并阅读原著，而不是把原著完整讲完。**
选段、画风、对白、分格、停点、封面与文案都围绕同一个有来源的原著卖点；不是每格插广告，也不为拉搜虚构原著。
用户明确要求完整漫画化时把该目标记入简报后再执行；原创故事和只处理已有图片的任务不强套推广。

**画面准确、对白与内心有来源、必要信息清楚、各话不跳过正在讲的事，是硬性要求。**
小说叙述不等于漫画必须另配讲解旁白；先让画面与人物原有言语/内心讲故事，不为解释版式而增写旁白。
推广节奏和悬念不能压过它们：先让读者看懂，再让读者想继续读；必要内容宁可增格增页，不能靠省略让人猜。
上一话正在进行的事件，下一话必须接着推进、画清解决，或在漫画里有依据地明确暂缓且继续记为未结，绝不能莫名消失。

## Quick Start

```text
用 $static-comic 将我获准改编的 输入/小说.txt 第 1–2 章改成第 1 话，
用于抖音和小红书图文推文，一页多格、竖版 3:4；目标是让读者搜索并阅读原著，不是完整漫画化。
先确定真实卖点、原著位置、剧透边界与停止点，核对准确书名；画面表达准确，台词旁白详细明确。
续话必须读上一话实际结尾，逐件承接未结事件，再做分页分镜、逐格提示词和末页搜书文字；止步于文本。
```

有已接受的格图后，使用本技能的 [本地排版工具](scripts/comic_tool.py)：

```bash
# 只检查分镜、文字 ID、交接记录、坐标和顺序，不需要第三方依赖
python3 {技能目录}/scripts/comic_tool.py check 项目/第001话/排版.json
# 续话必须提供实际上话；不靠会话记忆续写
python3 {技能目录}/scripts/comic_tool.py check 项目/第002话/排版.json --previous 项目/第001话/漫画分镜.md
# 进一步核对所有格图文件已就位；不代表图片已通过内容审查
python3 {技能目录}/scripts/comic_tool.py check 项目/第001话/排版.json --media
# 首次渲染才需要 Pillow，以及创作者提供的可用中文字体
python3 -m pip install "Pillow>=10.4,<12"
python3 {技能目录}/scripts/comic_tool.py render 项目/第001话/排版.json \
  --font <中文字体.ttf或otf> --out 项目/第001话/发布-v1 --format png
```

只在安装、升级或排障时运行 `python3 {技能目录}/scripts/selftest.py`。

## 入口与范围

1. 先找到用户点名的小说、脚本、已有分镜或格图；只有书名或有多部候选却没选时，询问文件和章节范围，
   不因仓库中有 `.txt` 就自行挑选、全量读取或改编。只处理用户有权使用的材料。
2. 已确认是一页多格、用于抖音/小红书图文时，不再问视频模型、时长、配音和运镜。
3. 用户未定画幅时，提出 1080×1440（3:4）、统一页尺寸、从上到下且同行从左到右阅读的起点。
   普通叙事默认一页多镜，单镜独幅/大幅通常用于重要转折；格数、大小、横竖和组合不固定。先试少量页面是 `craft_default`，不是页数配额或平台限制。
4. 小说改编默认采用上述推广目标，不再把“完整讲完一个章节/故事”作为默认完成标准。
   简报记录准确原著名、作者（已知时）、可选已核实阅读平台和搜索词；不能从文件名后缀猜书名或编造阅读入口。
   信息缺失可先做候选分镜，不能把未确认搜书卡标为可发布。
5. 连载续话先读取实际上话的当前分镜与末尾状态；缺上话不能假定事件已解决或改成独立篇逃避。
   同一本书已连续的推文默认继续；独立选段须有创作者明确批准，且不能对观众伪称连续后续。
6. 只要文本就停在文本；只要排版就不重写故事；有完整脚本可直接分格。用户未要求的生产、独立审查和发布不自动开始；交付前的内容自检仍要完成。

## 创作文件与所有权

不初始化 `short-drama.json`，不把漫画塞进视频的五文档或 Dashboard。漫画工作区按需建立：

```text
项目/
  创作简报.md                 # 推广目标、原著定位/卖点、剧透边界、停点、画风和搜索信息
  视觉设定.md                 # 人物/服装/场景/道具及持续状态
  第001话/
    漫画分镜.md               # 话头交接→页→格→文字；信息/衔接、画面提示词及文字的唯一正文
    排版.json                 # 仅位置、格图路径、文字 ID 与字号，不复制对白或提示词
    发布文案.md               # 完整推广交接时需要；标题/简介、准确搜书信息、上传顺序与授权待办
    制作成果/格图/             # 用户提供或明确确认后生成的真实图片
    发布-v1/                  # 工具导出的 PAGE-001.png 等；新版本用新目录
```

《漫画分镜.md》用 `## PAGE-001`、`### PANEL-001-01`、`#### TEXT-001-01` 组织。
首个页前写本话/上话号、连载关系、入口/出口及稳定事件 ID 的承接/待续记录，引用实际格或文字，不建另一份剧情台账。
每页有本页职责，每格有来源、读者应获得的**信息**、一个可见瞬间、具体**衔接**和完整的无字提示词。
对白写逐字台词、说话人和对话对象；内心写归属；旁白写明确叙述身份与完整正文，不能用梗概代替。
排版 JSON 通过同一个 ID 取字，正文修改只改 Markdown。格式与工具边界见 [排版格式](references/layout-format.md)。

## 工作流

### 1. 小说选段与改编简报

- 续话先读上一话最后几页与待续事件：正在做的动作/交涉、刚问的话、人物关系与已知信息、持物和伤势状态。
  每个待续项在本话落实继续、解决或明确暂缓，并引用本话图文；继续/暂缓仍留待续，不许在制作备注里虚标完成。
- 对短选段直接读用户指定范围；长篇可选用 `$short-drama-novel-analyze` 的章节索引和事实提取，
  只借人物、事件、伏笔及来源，不照搬短剧的秒数、分集数量和改编价值结论。没有该技能也可完成当前选段。
- 把必须保留的因果、人物动机、关系与暂不能揭示的信息写进简报；新增、合并、前置、删减均说明来源与影响。
- 推广初篇先选能代表原著吸引力、用较少背景即可理解的片段，不将小说“一章”机械当作“一篇推文”，不默认从第一章顺序画起；已开始的连续事件不能借选段规则被跳过。
- 在简报里写明主卖点及来源、目标读者、本篇给到的真实体验/小兑现、要留给原著的具体问题、停止位置与理由。
  区分已展示、保留、禁止泄露；不完整剧透主线，不捏造原著没有的爽点或关系来拉搜，也不把删掉动机造成的困惑当悬念。
- 确认原著名与本篇标题不同的职责，记录准确书名、已知作者、可选已核实阅读平台及搜索词。
  推广选段、停点与搜书承接见 [小说推文做法](references/novel-promotion.md)。

### 2. 视觉设定

- 围绕原著卖点选择清楚、可辨识且不误导题材/关系的视觉方向，不只追求无关的华丽画面；记录时代、角色身份锚点、固定发型/服装、场景地理、关键道具及跨页状态。
- 可选请 `$short-drama-assets` 协助梳理视觉事实，但本项目仍由本技能把接受结果写入唯一《视觉设定.md》，
  不同时维护另一份 `剧集/EP.../视觉设定.md`。人物姿势、表情和站位是本格瞬间，不锁成永久设定。
- 镜头含回忆/梦境或阶段切换时，按画内实际时期核年龄、服装与创作者的制作分工，不把整话的阶段表套到每格；源未给年龄先标待核，不借参考卡或“稍长大”补成原著事实。
- 有参考图先检查实际图片再登记：文件路径、中文名、顺序、用途和允许/禁止影响的范围；
  仅有提示词或待出图计划不等于已有参考图。旧库不同版本不平均成新画风：指定一个主身份/渲染锚，其余参考各限用途；允许改服饰不等于允许改脸、发色/瞳色或基础发型。

### 3. 按页与格讲故事

- 先把上话出口与本话入口对齐，再安排每页信息变化与翻页揭示，每格写具体“信息”和“衔接”，据此选关键瞬间。漫画可以定格结果、接触或反应，
  不受视频“关键帧只投影镜头起点”的限制。
- 一格只画同时可见的状态；“推门→走入→坐下”拆格，不能塞成单张图的时间轴。
- 先核原文的直接对白、人物内心、叙述与编辑说明，不把小说的每段叙述都搬成漫画旁白。对白/内心优先让人物自己讲故事，场景已画清的信息不再重复讲解；必要时空/因果仍需交代，源无依据不另添解说。身份/听众在分镜中明确，不代表必须画出姓名标签。
  写完整台词与必要解释，不交“两人交谈后解决”的梗概；声音转拟声字或可见反应，不依赖播放声音才能理解。
- 重要递交、对质、受伤、逃离和关系改变要有过程及结果；转场/倒叙在漫画中可辨认，不能在两话之间悄悄解决。
  详细不是堆字：信息足够就不重复，信息不足就增格增页，没有固定对白字数或旁白越少越好的门槛。
- 普通段落用一页多镜推进，单镜独幅/大幅通常强调重要转折或情绪落点，不强制每个转折占整页。格数、大小、横竖与组合随剧情、阅读顺序和字量调整，不套固定双横格/等大网格。
- 一张无字格图只是素材，不等于一张发布页；不由素材张数定页数。可从已有图裁取有叙事功能的反应/细节，但不能假装新增动作或为凑格数重复同一信息。
- 推广模式首张展示有原著依据的吸引点，中段给必要铺垫与真实体验，末页停在有具体续读理由的位置。
  可以给小兑现再留更大的问题；不是一味卡爽点，也不在漫画里讲完核心谜底或大结局。每页/格服务卖点、理解、体验或搜书承接，不强制每页反转。
- 搜书信息准确且不冒充角色台词。默认可安排末页提示；创作者要求故事优先/不占画面时，明确改放《发布文案.md》等画外信息，不强塞广告格或讲解旁白。画内采用时正文仍在独立`TEXT-*`，排版只取ID；不能挡住证据和表情，放置策略与例外记入简报。
  详细图文与跨话硬要求见 [信息与连续性](references/information-and-continuity.md)，分格见 [漫画页叙事](references/page-craft.md)，推广见 [小说推文做法](references/novel-promotion.md)。

### 4. 逐格提示词与图片交接

- 每格提示词包含同一句接受画风、可见角色与状态、构图、光色、连续性事实及文字预留区；
  明确不绘制气泡、对白、旁白、拟声字或水印。确需的画内文字也先留位置，后期准确排入。
- 每格实际图片与排入文字要逐项满足该格“信息”，角色/动作/物件错误就修复；不能拿提示词已写或文件存在当作表达通过。
- 优先“逐格无字出图→拼页→排字”。整页出图可作构图草稿，不默认作为文字正确的发布成品。先核一格的画风/身份再用于连续性；偏风格的废稿不作为后续渲染锚。核对原生字/刘海等身份漂移，记录未采用稿与真实调用次数，不以成功出文件代替验收。
- 本技能不捆绑出图服务。用户可自行出图并放回项目；实际调用外部生成前，先展示本批完整提示词、
  数量、参考、尺寸、输出和费用信息（已知时），取得针对该批的明确确认。不能把“继续”当成付费确认。
- 不直接把 `PANEL-*` 交给 `$short-drama-produce` 的 creator-first `source_entry`：它只支持现有的
  `IMG-*`/`SHOT-*` 等选择器。本轮不改该生产契约；确需复用时由该技能另行建立它支持的生产规格、
  展示逐格映射并执行自己的预览/确认流程，不能声称原生支持漫画项目或绕过校验。

### 5. 拼页、排字与图文交接

- 基于实际格图选择裁切焦点，避开脸、手、证据和气泡预留区；有信息裁不进去时改版式或重出该格，
  不靠遮住信息凑尺寸。气泡尾指向说话人，前后阅读不能交叉。
- 先实看创作者指定的旧贴字成品，拆出字体、字色、框形、透明度、位置/尾巴与阅读顺序，不抄旧剧情错误。图内贴字优先利用自然低细节背景，保留画面为主体；不用大框/白带为工具省事。`image_rect`白带/侧栏只是可选布局，不是漫画必需；用户拒绝时不用。空间不足先改构图/分镜，不缩字、遮关键表情/接触点或删故事。
- 新参考可选择轻椭圆对白、小半透明矩形内心/叙述，用角色浅/深同色系与完整字体协同；矩形内心仍是人物主观，不因框形变全知旁白。按类型选择对齐/细描边，避免所有文字统一粗白描边；无对应源文字不造台词/旁白演示样式。
- 创作者要求细白分隔时，按源图片真实尺寸看参考，不按聊天缩放坐标猜粗细；格坐标、外边和格框一起调，检查输出实际像素及近似缩览。`margin: 0`不会自动移格/消白缝，`panel_border_width: 0`可去格框；不把某次像素值、三等格或全幅变成普遍模板。
- 按已接受分镜生成《排版.json》，调用 `check`；图齐后用 `--media`。续话的 `check` 和 `render` 都带 `--previous 上一话/漫画分镜.md`，不能漏掉上话待续 ID。文件存在不是图像内容通过。
- 先约定辨识策略，不把“读者能辨识”偷换成“必须画姓名”。`lettering.mode: embedded`不画姓名/类型标签，靠全正文字体、字色、气泡/内心样式、位置与尾巴协同；身份/听众仍在真源。`labelled`保留旧可见名签作为另一种选择，旧布局未配置时维持兼容。工具按所选模式测量实际字形/宽高，放不下失败，不暗缩字、删词或覆盖旧版。
- 主角专属字体要真实作用于文字：embedded下`--speaker-font '姓名=字体路径'`用于该角色全部对白/内心正文，并配稳定可读字色/泡形；不要只换名字的小标签。labelled兼容模式仍只换名签。字体差异、颜色、位置和泡形共同帮助辨识，不以色差替代实际阅读自查。半透明底用`bubble_opacity`，字保持不透明，按背景选择细描边或深字无描边；可用`lettering.kinds`区分类型样式/对齐/描边、人物`dialogue_color`/`thought_color`区分同色系；必要时用只引用源字符位置的`breaks`自然断句，不能复制或改写正文来凑框。
- 字体路由先看文字类型/说话人，不因旁白正文提到某角色姓名就套其内心字色或专属字体。源标画外声时，气泡可靠侧缘/短尾朝画外，不误指没有发声依据的照片/遗照；不为展示字体新增内心或台词。先查源中环境字，避免新旁白与牌匾等原生字争读。
- 整话未齐图时可用 `preview --page PAGE-...` 明确选已齐图的局部页试排；仍查全话结构与实际上话，仅解码所选媒体。不能假造首话/独立篇或把 `preview_rendered` 当成全话媒体/发布通过；全话 `render` 仍须齐图。页内也未齐图时，页级preview仍应失败；可用项目内受限复现或外部编辑器做标清格ID的单格证明，保持真实源/话头及未核其余媒体标记，不以拉伸/占位/假首话冒充完整页；公共工具并未因此支持任意格选择。
- 在手机近似显示尺寸逐页看，核对中文字、说话人、阅读路径、人物一致性与裁切；这是创作自检，
  不是独立 reviewer verdict，工具不能替代。再将上话出口、本话入口/出口和每个事件的图文落点逐项核对；有信息/因果缺失先修复，不能把结构通过标为叙事通过。
- 完整推广交接包括编号PNG/JPG和《发布文案.md》，按已约定的画内/画外位置交付搜书信息：原著名、搜索词与简报一致，封面/正文/简介中的读书承诺有依据。
  采用画内提示时核其真实进图、可读且不挡剧情；采用画外时不强塞回画面。不编造免费、完结、独家或排名等宣传信息。仅文本/仅排版请求不自动扩展任务，未做项标待完成。
- 不转成 MP4，不声称已经上传、平台审核通过或有流量保证；按当次有效规则检查推广与 AI 标识、搜书引导方式。
  平台预览与发布待办见 [图文发布](references/social-publishing.md)。

### 6. 每轮交接与技巧回写

- 每轮先读项目工作记忆与当前真源，结束更新实际文件、依据、检查、未决与下一步；只存交接，不复制对白成为第二真源。
- 交付渠道须可访问。创作者要求远端分支可见时，在其明确授权和仓库规则内提交/推送必要文件，验证远端分支与文件存在并给直达链接；本地viewer或仅commit不能冒称远端交付，也不把全部缓存/废稿搬进Git，更不等于上传漫画平台。
- 轮末默认给出2–3个可执行的下一步选项，标出推荐项及前置条件/是否需另行出图确认。创作者明确要求每次回复都给选项时持续遵守；选项不替代正在执行的明确任务，也不重复询问已认可的方向。
- **本轮出现的可复用制作优化，同轮回写本skill**：操作原则归主工作流，分格/图文经验归页叙事，生产排障与检验边界归制作技巧参考，确定性接口归排版格式。不要只写项目存档或等全部制作完再补。
- 记录技巧的适用条件、做法、实际核验及失效边界，区分`reviewed_invariant`/`craft_default`/`taste_option`；未验证建议明确标出，不升级为普遍门槛。作品专名/服装/参考路径和私人内容只留项目，不塞进通用skill。
- 画风认可、人物确认、图文自检、整页验收和平台发布分开记，不能用一项认可推定全部通过。具体做法见[制作技巧与持续回写](references/production-learning.md)。

## 完成条件

说明本次实际完成的是文本、格图、排版还是发布交接；列出准确的文件和未决项。
每格必要信息与对白旁白明确；续话说明实际核对哪一话、原有事件如何处理、哪些仍待续。有正在讲的事被跳过、只在制作备注补解释或虚标解决，都不合格，先修复再交付。
推广模式按请求范围说明“原著卖点、读者后续期待、准确原著名、搜书信息在画内哪个TEXT或哪份画外文案”；
原著忠实、剧透与搜索真实性由引用证据自检，不用几何检查分数冒充推广效果。
每轮结尾给实际可执行的下一步选项，并说明本轮优化回写了哪份skill资料；不让选项代替当前任务或自动触发费用。
没有格图、没有中文字体或没有平台实际预览时如实说明，不把模板、自检通过或占位图称为漫画成品。
