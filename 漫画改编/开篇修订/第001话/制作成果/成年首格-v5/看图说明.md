# 成年首格 v5｜局部贴字，不是完整第1页

2026-10-25｜创作者选择A后，只为现有灵堂首格套用v5贴字。**没有新生图、没有改写正文、没有补造其余缺图。**

![成年首格局部贴字](PANEL-001-01.png)

## 实际处理

- 左侧是原有第三人称旁白：小半透明矩形、深灰黑字、左对齐、无描边。右侧是原有来客画外对白：轻椭圆、浅灰字＋1px深细描边，短尾朝右侧格缘，不指向遗照。
- 两块文字均按唯一分镜的类型/身份读取，不加姓名/类型标签；正文中的自然人名与称呼保留。**旁白提到男女主，不等于男女主在发言**，因此本格实际字体是Noto Sans CJK SC Regular，不强套苏梨内心的酒红文楷，也不为演示霍谢山字体添加台词。
- 正文34px，按横幅与实际字体主动选择，保留全部文字与标点；用源字符断点[8]、[4]分完整短语，不复制正文进排版JSON，也不是工具超框后自动缩字。
- 底88/255、字100%不透明，格外框0；矩形与椭圆均叠在画面里，没有额外白色字带。初试左上旁白与原画祭文牌匾争读，已移到左侧较低位置；与右侧泡同一阅读行，遗照、苏梨背影主体与持花手可见。

## 范围与来源

- 输出984×432 RGB PNG，保持当前格的横幅比例。它是`PAGE-001`的`PANEL-001-01`，**不是新增独幅故事页**，不拉成长竖版、不填白色占位凑页；单格也没有可展示的格间分隔线。
- 原图仍是1024×504 RGB裁切，来自固定旧提交`cf408fb5…`的P1上格[0,0,1024,504]。按当前格等比铺满、居中取景，不拉伸、不重绘；原图SHA与前轮一致。
- 已比较贴字前后同取景像素：遗照、苏梨头部/背影主体、持花手的保护区域逐像素相同；文字区域之外的像素也完全相同。具体区域与输入/输出/字体/布局/代码SHA在[来源与范围](来源.json)。
- 五份分镜、所有旧PNG及前四项成年提示词不改。布局只改首格两字框并补来客画外字色；第8–9页的v5原图/排字参数不变，旧收据不换新SHA。接回全页还需按另外两格真图重排。
- `PAGE-001`另两格仍缺，成年前两页共四项任务仍等创作者回图。标准页级preview与全话media仍应在缺图处拒绝，本单格输出不绕过该闸门。
- 已看984×432实际探针与360×158软件近似缩览，正式PNG哈希一致；这只是创作自检，不是实机、抖音/小红书或独立审查。本轮新增模型调用0。

## 复现

```bash
python3 漫画改编/工具/复现单格.py \
  漫画改编/开篇修订/第001话/排版.json \
  --panel PANEL-001-01 \
  --font "$HOME/.cache/drama-tools/NotoSansCJKsc-Regular.otf" \
  --out /tmp/adult-panel-check-new
```

本次实测Python 3.11.2 / Pillow 11.3.0，字体按`漫画改编/字体来源.json`的固定blob恢复；重现同SHA优先使用同版本，跨版本须重新核像素/字体。

目标必须是新目录。这个项目脚本先核真实全话结构/交接，仅为所选格读图与测字，输出PANEL文件与范围收据；只接无EXIF静态RGB PNG、embedded、无`image_rect`。它不是公共排版器新增的`preview --panel`，不支持任意图层；其他形式明确失败，不静默转换。
