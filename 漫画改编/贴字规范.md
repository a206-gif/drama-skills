# 画内贴字、半透明气泡与主角专属正文字体

2026-10-25｜以创作者最新反馈为准，**替代旧实白名签/独立白字区方案**。原图画风仍沿已认可方向，不重问画风。

## 当前呈现规则

- 文字直接嵌入画面；不为排字另裁白带/侧栏，不把独立文字卡当剧情镜头。
- 不显示“姓名｜对白/内心”“旁白｜身份”等标签。源分镜仍保留类型/说话人/听众，供制作与校验，不要求观众读技术字段。
- 用实际正文的字体、字色、气泡/内心样式、位置/短尾巴协同辨识。姓名自然出现在角色台词中时照原文保留，不是删除故事中的人名。
- 气泡底/边为半透明，正文100%不透明并有2px浅描边；降低的是遮画的不透明度，不把字也淡掉。当前底88/255（约34.5%不透明）是试排参数，不是固定公式。

小说本来有第三人称叙述，但它不是现成写着“旁白”的漫画剧本。是否转成画内旁白由信息需要决定，不因有叙述段就整段搬入。

- 原著L152的“妈妈？”保留为苏梨对白；母亲关怀按L154源意压缩。
- 原著L162是苏梨意识到九岁重生的认知，本轮转为第一人称内心；不再配“再睁眼时，她……”的讲解框。
- 第9页母亲原有提议拆为两个泡，合起来逐字等于旧台词；苏梨认出秦音的内心保留。没有把她提前写成知道系统。
- 本轮8–9页没有第三人称解说。其余未制作页的原著必要叙述逐页核对，不一刀删掉时空/动机，也不添无来源信息。
- 搜书信息迁各话《发布文案.md》，不加故事广告卡、不让角色念推广词。

## 参数、来源与复现

三份当前`排版.json`显式设置`lettering.mode: embedded`及人物字色/泡形。省略`image_rect`保持真实图片满格；`breaks`只记真源字符断点，避免“九岁那/年”“陪/你”等不自然断行，不复制正文。

三字体固定Git blob与原始OFL许可见[字体来源](字体来源.json)和[字体许可](字体许可/)。二进制只缓存，不入Git；恢复下载按来源JSON中的repository/blob显式`gh api .../git/blobs/...`解码后核Git blob，不能用同名不同字体冒充。字体许可不代替原著/旧图权利。

```bash
python3 漫画改编/工具/验证排字.py \
  --font "$HOME/.cache/drama-tools/NotoSansCJKsc-Regular.otf" \
  --speaker-font "苏梨=$HOME/.cache/drama-tools/LXGWWenKai-Medium.ttf" \
  --speaker-font "霍谢山=$HOME/.cache/drama-tools/NotoSerifCJKsc-Bold.otf"
```

此命令测当前实际三份JSON/相邻记录和五稿152个文字块的字形/字号，**不输出漫画、不核全套媒体**；不要加`--write-layouts`覆盖当前候选。标准渲染/preview仍显式给三字体参数，续话另给实际上话。旧纯标签sample参数只是旧兼容调试，不作本项目新视觉样张。
