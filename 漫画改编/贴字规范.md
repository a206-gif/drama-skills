# 可见文字身份与主角名签字体

本轮候选已真实试排，不是只有字体名称的建议。

## 读者实际看见什么

| 文字 | 可见身份 | 框体 | 字体 |
|---|---|---|---|
| 角色对白 | 姓名｜对白 | 圆角实白底；真图到位后定尾巴 | 正文统一清晰黑体；姓名名签按角色字体 |
| 角色内心 | 姓名｜内心 | 椭圆思考框；真图到位后定点尾 | 同上；不会成为其他人听见的对白 |
| 叙述 | 旁白｜具体叙述身份 | 矩形实白底 | 清晰黑体；第三人称、回忆、推广身份各自写明 |
| 系统发言 | 系统（仅秦音可闻）｜对白 | 对话框 | 脑内听众限定写在可见姓名里，苏梨开篇不能听见 |
| 音效 | 不加人物名签 | 描边字 | 画面必须有明确声源，不冒充对白 |

- **苏梨名签：霞鹜文楷 Medium，楷体。**
- **霍谢山名签：Noto Serif CJK SC Bold，粗宋体。**
- 正文/默认名签：Noto Sans CJK SC Regular，清晰黑体。
- 候选正文40px、名签30px；末页推广尾栏正文36px、名签27px。1080×1440下实测，不是平台官方要求。
- 两位主角只在名签换字体，长正文不改成花字。黑白下也有人名和类型，不能只靠粉/蓝或读者猜测。
- 名签自动从当前分镜的“说话人/叙述身份/类型”生成，不手抄进 JSON。人物名按完整字段精确匹配，不自动猜昵称。
- 字体与底色均以读清为先；不用低透明度字框。实际格图到位后再定遮挡与尾巴，不能拿空底样张冒充漫画完成。

## 字体来源与许可

固定二进制 Git blob 与原始许可见[字体来源.json](字体来源.json)和[字体许可](字体许可/)。三款字体均按源仓库 SIL OFL 1.1 留档，未修改、未将大体积字体二进制入 Git；本轮实际文件在工作缓存，缓存消失不影响分镜真源。

这只说明字体来源/许可，不证明原著推广改编权、旧图使用权、平台发布或搜索入口已获确认。

需要恢复本轮字体时，可在仓库根执行下列**显式下载**；脚本不会自动随排版运行：

```bash
python3 - <<'PY'
import base64, hashlib, json, subprocess
from pathlib import Path
fonts = json.loads(Path('漫画改编/字体来源.json').read_text(encoding='utf-8'))['fonts']
destination = Path.home() / '.cache/drama-tools'
destination.mkdir(parents=True, exist_ok=True)
for item in fonts:
    api = f"repos/{item['repository']}/git/blobs/{item['blob']}"
    response = json.loads(subprocess.check_output(['gh', 'api', api]))
    data = base64.b64decode(response['content'])
    actual = hashlib.sha1(f'blob {len(data)}\0'.encode() + data).hexdigest()
    if actual != item['blob']:
        raise RuntimeError('font blob mismatch')
    path = destination / item['filename']
    if path.exists() and path.read_bytes() != data:
        raise RuntimeError(f'refusing to replace a different file: {path}')
    path.write_bytes(data)
    print(path)
PY
```

## 弹性多镜排版与文字预算

- 最终一张发布图/漫画页可以有多个镜头，格数、大小、横竖与组合不固定；独幅/大格通常强调重要转折，不默认一张生成素材一页。
- 不先定死双横格/等大网格再把台词塞进去。先定页面信息重心和阅读顺序，再结合完整正文与名签预算安排图、格、框；放不下就调整布局、镜头分配或分页，不靠省字、藏标签或自动缩字。
- 页面变化仍保留人物姓名/文字类型、清楚的说话指向和关键脸手动作。候选JSON的字形/几何通过不等于已完成实图遮挡或手机阅读验收。

## 复核当前文字与版式

```bash
python3 -m pip install 'Pillow>=10.4,<12'
python3 漫画改编/工具/验证排字.py \
  --font "$HOME/.cache/drama-tools/NotoSansCJKsc-Regular.otf" \
  --speaker-font "苏梨=$HOME/.cache/drama-tools/LXGWWenKai-Medium.ttf" \
  --speaker-font "霍谢山=$HOME/.cache/drama-tools/NotoSerifCJKsc-Bold.otf"
```

- 此命令核对原著hash、三话实际相邻交接/候选几何、五份分镜全部153文字块的字形与名签，**不输出漫画**。
- 首次准备时才加 `--write-layouts`；当前三个 `排版.json` 已存在，会拒绝覆盖。人工改变分镜/几何后请核对实际 JSON，不把重生成起步版式当成已验收版式。
- 另做样张可加 `--sample 新文件名.png`；同名存在会拒绝，正文仍从上述ID读。
- 项目工具只给三个完整开篇话准备排版；不替局部补稿伪造CH话头、独立篇或上话输入。
- 真正使用已接受格图导出时，用[通用排版器](../skills/static-comic/scripts/comic_tool.py)的 `render`，保留上述三个字体参数；第002/003话另带实际 `--previous`。没图时 `--media`/`render` 应失败，不用样张或色块顶替。

名签和正文一同检测缺字、宽高和椭圆安全内区；放不下报错。旧版布局需要增框/增页，不能删名签或偷偷缩字来刷通过。
