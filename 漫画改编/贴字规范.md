# 参考式画内贴字：椭圆对白、矩形内心与细格缝

2026-10-25｜以创作者最新附图为格式参考，**细化v4、替代旧实白名签/独立白字区方案**。只借排字与格缝，不借参考的剧情/人物。已认可童年画风继续沿用，不重问画风。

## 当前呈现规则

- 文字嵌入画面，不另裁白字带/侧栏，不把独立文字卡当剧情镜头。
- 不显示“姓名｜对白/内心”“旁白｜身份”标签；分镜仍完整保留类型/说话人/听众。自然出现在台词中的姓名照原文保留。
- **对白轻椭圆，内心/必要叙述小矩形贴角**；字体、同色系字色、位置与需要时的短尾协同辨识。矩形内心不是无归属的全知旁白。
- 底/边半透明，字100%不透明。对白用浅色字＋1px深细描边；矩形内心/叙述深色字、不描边、左对齐，避免一律粗白描边。当前底88/255约34.5%不透明是试排选择，须随背景实看，不是固定公式。

## 外边与分隔：别让白缝吃画面

新两页用1080×1440满幅、外白边0、格外框0；第9页上下两格间只留**3px白线**，替代v4的24px白缝及两侧粗黑边。字框仍避眼、脸与攥衣/抱持关键点，满幅不等于所有元素贴裁切边。

参考图原尺寸941×1672，实看近全宽亮线核心1–2px；3px是当前1080宽的近似视觉选择，不是平台标准，不硬推到每页。分镜数量、方向、大小和比例仍按剧情安排，不能为了像参考而强制三等格。

小说本有第三人称叙述，但不是现成写着“旁白”的漫画剧本；只在必要时按信息需要转为画内叙述，不整段搬运。

- 原著L152的苏梨对白保留；母亲关怀按L154源意压缩。L162人物意识到九岁重生的认知，前轮转为第一人称内心，本轮不再改字。

## 参数、来源与复现

三份`排版.json`用`lettering.mode: embedded`；`kinds`区分椭圆对白/左对齐矩形及描边，`speakers`映射人物全文字色，`dialogue_color`/`thought_color`可分别配同一人物的浅/深色。`canvas.panel_border_width: 0`不画格外框；间隔由真实格坐标确定，`margin: 0`本身不会自动移格或消白缝。新两页不设置`image_rect`，图片满格；`breaks`只记源字符断点，不复制正文。

[用户参考来源](贴字参考/用户参考来源.json)存原图尺寸/哈希及小参考用途。三字体固定Git blob和原始OFL见[字体来源](字体来源.json)/[字体许可](字体许可/)；二进制缓存不入Git，恢复按来源JSON中的repository/blob经`gh api .../git/blobs/...`解码并核Git blob，不能同名冒充。字体许可不替代原著/旧图/用户参考的使用权。

```bash
python3 漫画改编/工具/验证排字.py \
  --font "$HOME/.cache/drama-tools/NotoSansCJKsc-Regular.otf" \
  --speaker-font "苏梨=$HOME/.cache/drama-tools/LXGWWenKai-Medium.ttf" \
  --speaker-font "霍谢山=$HOME/.cache/drama-tools/NotoSerifCJKsc-Bold.otf"
```

此命令测当前三JSON/相邻记录及五稿152文字块的实际字形/字框，不输出漫画、不核全套媒体；不要加`--write-layouts`覆盖现有候选。局部试排用工具`preview --page`，标准渲染/preview显式给三字体参数，续话另给实际上话。旧labelled sample只是兼容调试，不作当前视觉样张。
