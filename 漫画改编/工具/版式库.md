# 漫画版式库｜LAYOUT LIBRARY（2026-10-21 立）

> **立这份库的原因**：第 02–10 话全部是「上中下三等分三格」，读者看到第 10 话会觉得每一页长得一样。
> 从第 11 话起，**版式必须换着用**；但从 01 话延续下来的「细白缝、无黑框、满幅厚涂」版式语言不变。
>
> 一句话：**格子怎么切要变，画风与锁脸规则不变。**

---

## 一、版式总表

| 代号 | 结构 | 格数 | 主用途 | 一话内上限 |
|---|---|---|---|---|
| `L3-V` | 上中下三等分 | 3 | 对话推进、信息交代 | 2 次 |
| `L2-W` | 上宽幅环境 / 下大特写 | 2 | 情绪停顿、场景交代 | 2 次 |
| `L3-T` | 上 2/3 大格 + 下 1/3 两小格 | 3 | 一击 + 两种反应 | 2 次 |
| `L3-B` | 上 1/3 两小格 + 下 2/3 大格 | 3 | 两种铺垫 + 一击 | 2 次 |
| `L4-Q` | 2×2 四格 | 4 | 群像、多人反应、快节奏 | 2 次 |
| `L2-D` | 左右竖向对开 | 2 | 对峙、对话、双人关系 | 2 次 |
| `L3-S` | 整页大格 + 底部窄条 | 3（1 大 + 1 条 + 1 小） | 大场面 + 关键细节 | 1 次 |
| `L5-T` | 上横条 + 中两格 + 下横条 | 4 | 时间推进、连续动作 | 1 次 |
| `L-S` | **单镜整页** | 1 | 转折点 / 名场面 | 1 次 |

**硬规则**
1. **相邻两页不得同版式**（第 11 话起执行）。
2. 同一版式一话内不超过上表上限。
3. 每话至少用 **3 种**不同版式。
4. `L-S` 单镜页一话最多 1 页，且必须通过下方「转折三问」。
5. 无论哪种版式：**细白横向/竖向分格缝、无黑框、无墨线、格内满幅厚涂**。

## 二、各版式图示与提示词写法

### `L3-V` 上中下三等分
```
┌─────────────┐
│             │
├─────────────┤
│             │
├─────────────┤
│             │
└─────────────┘
```
`exactly three equal panels stacked vertically, thin white gutters`
> 用途：对话密集、信息推进。**这是"默认页"，不是"唯一页"。**

### `L2-W` 上宽幅 + 下大特写
```
┌─────────────┐
│   wide env  │
│             │
├─────────────┤
│             │
│   close-up  │
│             │
└─────────────┘
```
`two panels: a wide panoramic panel across the top third, and one large close-up panel filling the bottom two thirds`
> 用途：先交代"在哪"，再给"谁在痛"。情绪页最好用。

### `L3-T` 上大格 + 下两小格
```
┌─────────────┐
│             │
│    big      │
│             │
├──────┬──────┤
│      │      │
└──────┴──────┘
```
`three panels: one large panel filling the top two thirds, and two smaller panels side by side in the bottom third`
> 用途：一击之后接两种反应（她的脸 / 他的手）。

### `L3-B` 上两小格 + 下大格
```
┌──────┬──────┐
│      │      │
├──────┴──────┤
│             │
│    big      │
│             │
└─────────────┘
```
`three panels: two smaller panels side by side across the top third, and one large panel filling the bottom two thirds`
> 用途：两条铺垫收束成一个大结果。

### `L4-Q` 2×2 四格
```
┌──────┬──────┐
│      │      │
├──────┼──────┤
│      │      │
└──────┴──────┘
```
`four panels in a two by two grid, thin white gutters`
> 用途：群像哗然、四人四种脸色、短平快的连续动作。

### `L2-D` 左右竖向对开
```
┌──────┬──────┐
│      │      │
│      │      │
│      │      │
└──────┴──────┘
```
`two panels side by side in a vertical split, a thin white vertical gutter between them`
> 用途：对峙、谈判、双人关系。**注意：左右格各自的人物必须点名，别让模型把两人塞进同一格。**

### `L3-S` 整页大格 + 底部窄条
```
┌─────────────┐
│             │
│   big       │
│             │
├─────────────┤
│   strip     │
├──────┬──────┤
│      │      │
└──────┴──────┘
```
> 结构说明：大格占上 2/3，中间一条窄横格（放关键细节/手部/道具），底部一格收尾。
> 提示词：`one huge panel across the top two thirds, a narrow horizontal strip panel beneath it, and one final panel at the bottom`
> 用途：大场面 + 一个决定性细节。比 `L3-V` 更有呼吸感。

### `L5-T` 横条 + 两格 + 横条
```
┌─────────────┐
├──────┬──────┤
│      │      │
├─────────────┤
└─────────────┘
```
> 提示词：`four panels: a wide horizontal strip at the top, two equal panels in the middle row, and a wide horizontal strip at the bottom`
> 用途：时间推进（早→午→晚）、连续动作。

### `L-S` 单镜整页（重点场面的精致插画）
```
┌─────────────┐
│             │
│             │
│  single     │
│  cinematic  │
│  key art    │
│             │
└─────────────┘
```
> 提示词：`ONE single full-page cinematic illustration, no panel borders, no panel divisions, no gutters — the entire page is one uninterrupted painting`
> 版式语言仍需与全片一致（厚涂、克制配色），但**构图按插画走**：单一视觉主体、强光位、留白给贴字。

## 三、单镜页（`L-S`）什么时候用

**转折三问**（≥2 项为「是」才允许用）
1. 这一页是否改变了人物的命运、关系或认知？（不只是情绪起伏）
2. 把台词全部拿掉，这张画本身还能传达这一击吗？
3. 它是否紧接或引出一个不可逆的动作/决定？

**允许的例子**：当众揭穿、契约成立、挡刀瞬间、身份暴露、死亡确认、求婚/拒婚、第一次反击成功。
**不允许的例子**：日常对话、走路、吃饭、普通回忆、单纯好看的脸、连续两页都想"大图"。

**配额**
- 一话 ≤ 1 页 `L-S`。
- `L-S` 是**页**，不是 KEY CG：不占契约里「全批 ≤3 张 CG」的预算。
- KEY CG（无分格、封面级、可跨页）仍按原规则，全批 ≤3，且需创作者批准。

## 四、一话内的版式节奏（推荐模板）

以 5 页一话为例，**不要 5 页全 `L3-V`**：

| 页 | 建议版式 | 理由 |
|---|---|---|
| P1 | `L3-V` 或 `L2-W` | 开场交代地点与人 |
| P2 | `L3-T` | 抛出冲突 + 两种反应 |
| P3 | `L4-Q` 或 `L2-D` | 群像/对峙，节奏加快 |
| P4 | `L3-B` | 两条线收束 |
| P5 | `L-S` | 转折点，单镜收尾（若本话无转折则用 `L3-S`） |

**判断口诀**：**对话用多格，情绪用大格，转折用单镜。**

---

## 五、贴字注意（版式变了，气泡位置也要跟着变）

- `L-S` 单镜页：气泡最多 2 个，必须留在留白区（天空/墙面/虚化背景），不得压在眼睛与手上。
- `L2-D` 左右对开：气泡按格归属，`panel: 1` 是左格、`panel: 2` 是右格，**不要跨格压字**。
- `L4-Q` 四格：一页最多 3 条文字，否则会糊；优先保"最响的那一句"。
- `L3-S` 窄条格：只放短句（≤8 字）或音效，别放长旁白。
- 所有版式：`工具/贴字.py` 的 `panel_rects` 必须按实际分格重测，**不要沿用上一话的坐标**。

---

## 六、与提示词配合的写法

版式句固定放在提示词**第一句**（在 CAST LOCK 之前），模型才会先搭格子再放人：

```
A vertical full-color comic page in cinematic Korean webtoon style: <版式句>, separated only by thin white
horizontal gutters, no black frame lines, no ink outlines, full-bleed painterly illustration in every panel,
clean uncluttered space near panel edges for later lettering.
```

`L-S` 例外：**不写 gutters / panels**，改写
```
A vertical full-color SINGLE-PANEL cinematic illustration, one uninterrupted painting with no panel borders
and no panel divisions, full-bleed, clean negative space near the edges for later lettering.
```
（单镜页仍要写 `no panel divisions`，否则模型会自己加格子。）
