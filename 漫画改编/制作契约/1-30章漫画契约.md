# 1–30 章漫画改编契约（NVA-EPC-001…010）

依据：`项目开发/source-analysis/episode-candidates.jsonl`（10 候选）、`三阶段定妆设计.md`、
`PRODUCTION_SYSTEM.md`、`设定集/角色与画风档案.md`。本文档为创作者确认前的**制作契约草案**；
第 1 话按本契约试制、供创作者验效果。

## 一、总则

1. 叙事形式：COMIC PAGE MODE 为主（每页 1–4 格）；版式按 `工具/版式库.md` 轮换，禁止全话清一色上中下三等分：相邻页不同版式、同版式一话 ≤2 次、每话 ≥3 种；转折点可用 1 页单镜整页（L-S），一话 ≤1 页。单镜页属于“页”不是“CG”，不占下方 CG 预算；KEY CG MODE 仅限重大节点，宁缺勿滥。
2. 本批 CG 预算（1–30 章）：**全批 ≤ 3 张**。第 1 话 1 张（照片墙揭示=全书最大前提翻转）；
   其余候选默认 0 张，仅当创作者追加批准时在 NVA-EPC-005（ch11 杀狗记忆闪回）或
   NVA-EPC-008（ch19 项圈契约）追加。
3. 阶段定妆：EPC-002…008 用幼年期；EPC-009…010 用少年期；EPC-001 用成年期（25 岁）+ 幼年闪回插帧。
4. 未成年合规（ch6/7/17/28 等）：暴力用剪影/前后镜头/结果镜头表达，不给施暴过程特写；
   幼年角色一律清素着装；溺压/持刀段落画面降级、冲击力由分镜节奏与台词承担。
5. 文字：生图不生成中文（含气泡），先产无文字画面；对白/旁白/CG 文字随图交付（见各话脚本）。
6. 生图输入：单人女戏传参考-A；单人男戏传参考-B；同框两张全传。每图过 7 项锁脸校验。

## 三、第 1 话详细契约｜灵堂钩子（ch1，NVA-EPC-001）

**目标**：3 页内完成「她很幸运」→「幸运是他拿命换的」→「他一直在注视你」三级翻转，结尾钩重生。
**场景状态**：苏梨=黑色素雅丧服、银灰长发挽起、无首饰、病弱苍白；霍谢山=遗照/遗体（黑色西装、
黑狼尾长发、暗红眼瞳——遗照按参考图瞳色，不用原著"浓黑"）；灵堂=现代豪门厅堂、白菊、挽联、黑白遗像。
**CG 判定**：照片墙揭示=「关键秘密/真相揭示+重大意义场景首次呈现」，全书主题图，批准 1 张。

### 分镜脚本（无文字画面 + 对白文本）

**第 1 页「节哀」（3 格）**
- 格1（大横格·远景）：豪门灵堂全景——白菊花圈、黑白遗照（狼尾青年）、黑衣宾客持花。
- 格2（中景）：苏梨持白菊、神色恍惚特写。
- 格3（近景）：两名宾客侧目窃语，眼神艳羡。
- 对白：宾客A「霍太太，节哀。」／宾客B（窃语）「她命真好，那么年轻就……」／旁白：「他们都说，我好命。」

**第 2 页「创口」（3 格）**
- 格1（中近景）：苏梨俯身整理遗容，指尖触他瘦脱相的脸颊。
- 格2（特写）：被扯开的衣领内——瘦削胸膛上的手术创口与暗色血渍（克制、不血腥）。
- 格3（大特写）：苏梨瞳孔骤缩，手按上自己心口（健康的心跳）。
- 对白：助理「太太，别看！」／苏梨内心「心脏的位置……手术创口。我的这颗心，是从哪来的？」／旁白：「车祸，不是意外。」

**第 3 页「密室」（3 格）**
- 格1（中景）：助理递上遗嘱信封，立于一扇无窗厚重门前（电子密码锁）。
- 格2（特写）：纤细手指输入密码（暗示：她的生日），门缝透出幽暗。
- 格3（主观镜头）：门开——黑暗房间里监视器幽光浮起，隐约照出满墙照片的轮廓（揭示留给 CG）。
- 对白：助理「遗嘱说……请您去一个地方。」／苏梨内心「密码，是我的生日。」／旁白：「没有窗，像牢笼。」

**KEY CG「注视」**（单张完整插画，无分格）
构图：无窗密室内，满墙偷拍照（同一银灰长发女子的日常瞬间）+ 一面监控屏墙 + 旧物盘成巢状；
苏梨黑色丧服立于中央回望镜头，惊惧与震撼；霍谢山的影子以墙上海报/照片群像的方式"注视"她。
CG 文字（生成后叠加，位置=画面下缘留白）：「满墙都是我。」
QC 重点：无分格、苏梨锁脸、照片墙人物=同一人、氛围压抑唯美不恐怖谷。
