# 华夏守路人·分镜生成技能

## 技能概述

本技能用于为《华夏守路人》22季系列剧集生成标准化的分镜制作文档，确保每一集分镜的格式统一、字段完整、可直接用于视频生成。

**核心原则：** 时间轴细分是视频生成的直接输入，必须格式清晰、粒度合理、画面/音效/台词三者分离明确。

**⚠️ 禁用清单（严格禁止出现在分镜中）：**
1. 禁止出现「玄玉牌」「玉牌」等相关道具、符号、情节
2. 禁止出现「长生」「永生永世」等相关设定（主角只是一个长寿的守火人，不强调长生属性）
3. 所有符号和伏笔都要用剧情本身承载，不要用玄幻道具
4. **禁止出现「心跳声」**：所有音效中绝对不能出现心跳声，POV镜头也不能用心跳声作为音效

## 三、时间轴细分规范（最重要！）

### 格式标准

**每个时间段的格式：**
```
镜头：[景别]，[运镜方式]，[画面详细描述]；音效：[音效1]+[音效2]；**角色（台词类型）：**"台词内容"
```

> ⚠️ **运镜强制要求**：每个时间段必须明确标注运镜方式，不能省略！景别+运镜是画面的两大核心要素，缺一不可。运镜要与情节情绪匹配（紧张用手持/快推，温情用呼吸/缓变焦，史诗用升降/环绕）。

### 分段原则

1. **固定总时长**：每个镜头总时长固定15秒，不多不少
2. **内部分段灵活**：根据情节节奏在15秒内灵活分段（如0-3秒、3-7秒、7-11秒、11-15秒）
3. **关键动作单独分段**：表情变化、动作转折点、POV切换都单独分段
4. **每镜头3-4段**：15秒镜头分3-4个时间段，节奏最合理
5. **首尾铺垫**：第一段建立场景，最后一段为下一镜做铺垫

### 台词硬性规则（必须严格遵守！）

#### 规则1：单条台词字数限制
- 每条台词（一个角色说的一句话）**不得超过50个字**
- 超过50字的长台词，必须拆分为多条短台词，分配到不同镜头或同一镜头的不同时间段
- 拆分原则：按语义自然拆分，保持说话人不变，不改变原意，不删减内容

#### 规则2：台词完整性要求
- **绝对不能落下原文中的任何一句台词**，所有台词必须全部出现在分镜中
- **绝对不能更改原文中的任何一句台词**，一字不差，包括语气词、省略号、感叹词等
- 原文中台词的说话人、情绪、顺序都必须严格保持一致，不得调换顺序、不得合并或拆分说话人

#### 规则3：台词与镜头数量关系
- 如果一个场景台词较多，不要硬塞到一个镜头里
- 应该增加镜头数量，把长对话拆成多个镜头，每个镜头15秒
- 镜头数量根据台词总量灵活调整，宁可多几个镜头，也不能漏台词、也不能让单条台词超50字

#### 规则4：台词核对方法
- 生成完成后，必须逐句对照原文剧本核对
- 方法：把原文所有台词列出来，和分镜中的关键对话清单逐一比对
- 确保：数量一致、内容一致、顺序一致、说话人一致

### 各元素规范

#### 景别（必须明确写出）
大远景 / 远景 / 全景 / 中景 / 近景 / 特写

#### 机位/运镜（每个时间段必须明确写出！）

**基础推拉摇移（最常用）：**
固定镜头 / 缓慢推镜 / 缓慢拉镜 / 横移平移 / 升镜 / 降镜 / 左右摇镜 / 俯仰摇 / 环绕运镜

**手持跟随类：**
跟镜跟随 / 肩扛手持抖动 / 稳定斯坦尼康顺滑跟随

**变焦创意类：**
希区柯克变焦 / 快速急推变焦 / 缓变焦

**特殊视角类：**
主观POV视角 / 鸟瞰俯瞰 / 低角度仰拍运镜 / 微距微观推镜

**复合长镜头类：**
一镜到底 / 甩镜转场 / 回旋螺旋运镜 / 呼吸运镜

**转场专用运镜：**
遮挡运镜 / 穿越运镜

> 运镜选择原则：开场/结尾用推拉升降建立或收束空间；情绪镜头用推镜/缓变焦；战斗场景用手持抖动+跟镜；史诗大场面用升降+环绕；和平温情段落用呼吸运镜+斯坦尼康。

#### 音效
格式：`音效：[主音效]+[环境音]+[动效音]`
多个音效用 `+` 连接
音效要具体，不要只写"环境音"

#### 台词标注
**台词**：正常对话 `**角色（台词）：**"..."`
**情绪台词**：带情绪标注 `**角色（大喊台词）：**"..."` / `**角色（颤台词）：**"..."`
**内心独白**：`**角色（内心）：**"..."`
**旁白**：`**旁白：**"..."`
**无台词**：`（无台词，[状态说明]）`

#### POV镜头
POV镜头必须加粗标注：`**主观POV视角**` 或 `**角色的主观POV视角**`
POV镜头控制在3-5秒内
POV镜头必须配合音效（呼吸声、耳鸣声、环境音放大等，绝对不能用心跳声）

## 四、高阶分镜思维应用

### 叙事性转场（每集至少1个）
水流转场：特写水流→拉远成全景河流
火光转场：火塘火焰特写→叠化到另一处火光
色彩转场：色调渐变（暖→冷/明→暗）
物像转场：道具特写→另一场景同道具
动作锚定：上一个动作结束姿势=下一个镜头开始姿势

### 三层景深构图
**前景（虚焦）**：道具符号、环境质感、情绪暗示
**中景（实焦）**：人物主体、动作表情、核心信息
**背景（虚焦/半实）**：环境氛围、时代信息、空间挤压感

### 声音设计
音效参与叙事，不只是"环境音"
每个镜头要有独立的声音设计
全片要有核心声音符号（火塘噼啪、水流声等）

## 五、镜头设计专业标签库（借鉴ShotDeck体系）

> 每个镜头必须从以下6个维度进行专业定义，让视觉语言精确、有电影感。
> 借鉴 ShotDeck 的精细标签体系，每个维度选取最适合《华夏守路人》风格的标签。

### 维度1：景别 Framing

| 景别 | 视觉特点 | 适用场景 |
|---|---|---|
| **大远景** | 人物极小，环境为主 | 山河地貌、部落全景、战争场面、时代氛围建立 |
| **远景** | 人物占画面1/4以下 | 迁徙队伍、耕作全景、建筑外观、空间规模感 |
| **全景** | 人物全身入画 | 人物入场、完整动作展示、场景关系交代 |
| **中景** | 人物膝盖以上 | 对话场景、日常动作、情绪交流、主要叙事镜头 |
| **近景** | 人物胸部以上 | 表情细节、重点台词、情绪转折、观察镜头 |
| **特写** | 肩以上/局部 | 眼神、手部动作、道具细节、情绪爆发 |
| **大特写** | 局部极致放大 | 瞳孔、泪水、火光、极端情绪 |

| **翠绿色调** | 绿/青为主，清新明亮 | 生机、希望、新生、春天 | 江南、春天、开垦、重生 |
| **金红色调** | 金/红/橙为主，高饱和 | 辉煌、盛大、喜庆、悲壮 | 皇宫、盛世大典、壮烈牺牲、夕阳 |
| **水墨色调** | 黑/白/灰为主，极简 | 意境、哲思、留白、超脱 | 悟道、生死离别、山水意境 |
| **低饱和灰调** | 所有颜色饱和度低，偏灰 | 压抑、沉重、绝望、末世 | 灾年、乱世、亡国、苦难 |
| **高饱和暖调** | 色彩鲜艳浓郁，暖色为主 | 繁华、热闹、旺盛、节日 | 盛唐、集市、节日、繁华景象 |

### 维度5：镜头运动 Camera Movement

> 六大类运镜体系，从基础到高阶，每个镜头必须明确标注运镜方式。

#### 一、基础推拉摇移（最常用，分镜必备）

| 运镜方式 | 视觉效果 | 情绪/叙事作用 | 长生客适用场景 |
|---|---|---|---|
| **推镜 Push In** | 镜头缓慢向主体靠近，主体变大、背景收缩 | 聚焦、深入、紧张、沉浸 | 人物情绪特写、突出关键动作、进入场景 |
| **拉镜 Pull Out** | 镜头向后撤退，容纳更多环境，主体缩小 | 抽离、全局、孤独、落幕 | 大远景展现史诗感、场景结束、人物远去 |
| **横移平移 Dolly Side** | 镜头水平左右滑动，机位高度不变 | 展示、巡视、空间展开 | 扫过士兵阵列、横向展示两军对垒 |
| **升降运镜 Crane** | 镜头垂直上下移动（升镜往上/降镜往下） | 俯瞰、升起、庄严、宏大 | 从地面拉高俯瞰战场、从高空下落聚焦人物 |
| **摇镜 Pan** | 机位固定，镜头左右水平转动 | 环视、扫视、观察、对比 | 从黄帝军摇到炎帝军、对比两边人群 |
| **俯仰摇 Tilt** | 机位固定，镜头上下转动（仰摇上/俯摇下） | 高大、压迫、俯瞰、展现高度 | 仰拍首领高大身形、俯看战场人群 |
| **环绕运镜 Orbit** | 机位围绕主体360°/180°缓慢转圈 | 聚焦、强调、仪式感、重要时刻 | 两位首领握手、重要人物登场、核心道具 |

#### 二、手持跟随类（增强真实临场感）

| 运镜方式 | 视觉效果 | 情绪/叙事作用 | 长生客适用场景 |
|---|---|---|---|
| **跟镜 Follow Shot** | 镜头全程跟随人物移动，主体大小不变 | 代入感、临场感、紧张 | 士兵走动融合、阿生走上高地、赶路迁徙 |
| **肩扛手持抖动 Handheld** | 轻微不规则抖动，模拟人眼临场视角 | 真实、临场、紧迫、纪录片感 | 开战前对峙、逃难、战斗场景、紧急时刻 |
| **稳定斯坦尼康 Smooth Follow** | 顺滑无抖动长跟随，柔和流畅 | 温情、史诗、庄重、连贯 | 首领并肩行走、和平融合、温情段落 |

#### 三、变焦创意运镜（含希区柯克变焦）

| 运镜方式 | 视觉效果 | 情绪/叙事作用 | 长生客适用场景 |
|---|---|---|---|
| **希区柯克变焦 Vertigo Zoom** | 拉远+长焦推同时进行，主体不变背景拉伸扭曲 | 冲击、震撼、内心剧烈波动 | 阿生看到两军握手瞬间的主观POV、重大发现 |
| **快速急推变焦 Snap Zoom** | 瞬间长焦推近，画面猛地聚焦主体 | 冲击、强调、突然发现 | 武器落地特写、首领握手手部特写、关键发现 |
| **缓变焦 Slow Zoom** | 缓慢柔和改变焦距，无明显镜头位移 | 安静、抒情、神圣、沉浸 | 夕阳远景慢变焦、神圣宁静氛围、沉思时刻 |

#### 四、特殊视角 & 空间运镜

| 运镜方式 | 视觉效果 | 情绪/叙事作用 | 长生客适用场景 |
|---|---|---|---|
| **主观POV镜头 POV Shot** | 完全模拟角色眼睛视角，所见=角色所见 | 代入感、真实感、第一人称体验 | 阿生观察战场、故人视角、回忆画面 |
| **鸟瞰俯瞰 Top-down** | 高空垂直90°向下俯拍，规整展示全局 | 史诗、宏大、全局、上帝视角 | 整片战场俯瞰、两军阵型融合、部落全景 |
| **低角度仰拍运镜 Low Angle Move** | 机位贴近地面向上，缓慢向前推 | 高大、威严、压迫、希望 | 黄帝炎帝首领出场、重要人物登场 |
| **微距微观推镜 Macro Push** | 镜头推向微小细节，极致放大 | 细节、质感、强调、仪式感 | 石斧落地、手掌交握纹路、羽毛兽皮纹理 |

## 六、图片/视频提示词生成规范（电影级输出）

### 核心原则
借鉴 ShotDeck 的专业标签体系，每个提示词必须包含**至少5个视觉维度标签**，让AI生成的画面具有电影质感。

### 图片提示词公式
```
[时代场景] + [人物动作状态] + [景别] + [构图方式] + [灯光类型] + [色调] + [镜头运动] + [情绪氛围] + [画质关键词]
```

### 视频提示词公式
```
[前置衔接说明] + [起始画面] → [结束画面] + [镜头运动方式] + [节奏/速度] + [光影变化] + [色调氛围]
```

### 电影级画质关键词（必加）
`cinematic lighting`（电影级灯光）
`cinematic composition`（电影级构图）
`ancient Chinese style`（中国古风）
`high detail`（高细节）
`8k resolution`（8K分辨率）
`atmospheric`（氛围感）

### 长生客风格专属关键词
`primitive tribal`（原始部落）—— 炎黄五帝季
`bronze age aesthetic`（青铜时代美学）—— 商周季

## 七、生成流程

当用户要求生成某集分镜时，按以下流程执行：

1. **读取输入**：获取分集剧本原文、上一集尾帧信息
2. **提取全部台词**：先把原文剧本中所有台词全部提取出来，列成清单，标记说话人和顺序
3. **拆解情节与规划镜头数量**：根据情节和台词总量，规划镜头数量（每个镜头15秒），确保每条台词≤45字，超长台词提前规划拆分
4. **设计镜头**：为每个镜头设计画面、动作、台词，确定每个镜头的核心运镜方式
5. **台词逐句填入**：把提取的所有台词逐句填入对应镜头，确保不漏一句、不改一句，每个镜头中的每条台词≤45字
6. **镜头设计六维定义**：从景别/构图/灯光/色彩/运动/情绪6个维度定义每个镜头的视觉语言
7. **时间轴细分运镜落地**：将每个镜头的运镜方式分解到每个时间段，确保每段都有明确运镜
8. **应用高阶思维**：添加三层构图、声音设计、转场方式（音效中绝对不能出现心跳声）
9. **完善细节**：填充图片/视频提示词（含电影级关键词）、风险点、3秒自检
10. **组装文档**：按标准结构组装完整分镜文档
11. **台词完整性自检**：对照提取的台词清单，和分镜中的关键对话清单逐一比对，确保：
    - 台词数量一致
    - 每句内容一字不差
    - 说话人一致
    - 顺序一致
    - 每条台词≤45字
12. **高阶分镜自检**：对照高阶分镜自检清单检查，重点核查每个时间段是否都有运镜标注
13. **禁用项核查**：最终检查，确保全文没有「玄玉牌/玉牌」「长生/永生永世」「心跳声」等禁用内容，如有必须全部删除
