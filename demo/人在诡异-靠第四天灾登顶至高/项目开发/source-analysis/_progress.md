## 推广片脚本的时长口径（重要，别被工具误导）

`剧集/EP000/剧本.md` 的时长**没有**用脚本自动换算，原因如下，写在这里以免下一轮重踩：

- 仓库里唯一有实测依据的中文语速是 **4.1 个可发声字/秒**（20 次对照生成，
  见 `short-drama-video-prompts/references/performance-action-timing.md`），它的计数口径是
  **剔除标点的可发声字**。
- 而 `duration_estimate.py` 用的 `dialogue_characters` **含标点**。
- 两者口径不同，技能明确要求「不把两个计数混用」。若把 4.1 直接绑进
  `/format/pacing/spoken_characters_per_second`，工具算出的秒数会系统性偏大。
  另外该工具的动作段落速率是**不可为 0 的正数**，等于要凭空造一个动作时长。

**所以 `/format/pacing` 保持 unset**，没有写入任何语速值。手算如下：

| 项 | 值 |
|---|---|
| 台词块可发声字（剔除标点） | **250 字** |
| 纯发声时长（250 ÷ 4.1） | **约 61.0 秒** |
| 画面文字块 | 6 处（倒计时、帖子、五个 ID、信仰值 -10 ×2、书名卡） |
| 加开场静默 3 秒、开口等待/停顿、反应镜头与落点停留 | 约 20 秒 |
| **合计** | **约 81 秒**，落在 60–90 秒内 |

这个 81 秒是**估算**。真要坐实，得等配音出来按实际录音核；在那之前不要把它当成已验收的时长。
