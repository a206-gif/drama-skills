# 全书爆点库（HK-01 … HK-24）

> 用途：**推广原著小说**的短视频选题池。每条短片的目标不是"追剧"，是**让观众看完去搜书名**。

## 选材口径

- **一条只讲一个爆点**，45 秒内讲完，不讲完整故事。
- **0–3 秒必须有冷开**——不铺垫、不介绍人物，直接给冲突或反差。
- **片尾必须留一个"必须去搜才能知道答案"的问题**。
- 旁白按 **4.7 字/秒**估算，45 秒 ≈ 150–190 字人声。

## 尺度分级

| 级别 | 处理 |
|---|---|
| 🟢 绿 | 直接用。打脸／护短／醋意／智斗／喜剧 |
| 🟡 黄 | 可用，**改成暗示**。seq 32–35、46–50、61–62、95–98 |
| 🔴 红 | 不用。seq 33、81–86、70 |

## 30–45 秒结构模板

| 段 | 时长 | 职责 |
|---|---|---|
| 冷开 | 0–3 秒 | 直接给冲突，不介绍人物 |
| 立人物 | 3–10 秒 | 一句话说清他是谁、他为什么在这 |
| 爆点 | 10–30 秒 | **这一条唯一的爽点**，给满 |
| 反转/钩子 | 30–40 秒 | 抛出新信息，改变观众对前面 30 秒的理解 |
| 片尾问题 | 40–45 秒 | 一句字幕 + 一句旁白，引导搜索书名 |

## 旁白口径

- 4.7 字/秒，45 秒 ≈ 150–190 字。
- **旁白为主 + 三两句真台词**：真台词保留口型同步，其余改旁白。
- 真台词只留**最有记忆点的一句**，多了就成广播剧了。

## 单部片钩子核查（2026-10-16）

> 系列片和单部片的钩子标准不一样：系列片可以靠"下一集揭晓"留人，
> **单部片只有一次机会，片尾必须把观众直接推去搜书名。**

### 书名拆解

**《被绝色国师掳走后，她竟要圈养我》** —— 三个钩子，缺一不可：

| 钩子 | 本片是否落地 | 出处 |
|---|---|---|
| 被绝色国师**掳走** | ⚠️ 部分（尾镜"冲天而起带走"，够暗示） | seq 3 |
| 她竟要**圈养**我 | ❌ **完全没有** | seq 3–4 |
| 绝色**国师** | ✅ 有（旁白"是当朝国师"） | seq 3 |

### 问题

EP001 原设计是 **HK-01 + HK-02 双爆点**（打脸认亲 ＋ 圈养反差），
但实际落地时只做了 **HK-01**——结尾停在：

> 旁白："也是他从未谋面的……姨。"

这是**身世钩子**，不是**书名钩子**。
观众看完记住的是"少年揍了捕快、被国师认亲"，
**不会联想到《被绝色国师掳走后，她竟要圈养我》这个书名**。

**核查结果**：`剧本.md`／`分镜.md`／`视频提示词.md` 里，「圈养」出现 **0 次**
（仅在 `分镜制作.md` 的剧名标题里出现）。

### 可用的原文素材（seq 3–4，全部干净、无尺度风险）

| 台词 | 原文 |
|---|---|
| 洛水漓 | 「你不仅要去秋月宗，从今往后，你只能留在我的身边，没我的允许，哪里也不许去。」 |
| 洛水漓 | 「从今往后，你就在我身边待着，哪里也不许去，我去哪你都要跟着。」 |
| 洛水漓 | 「你出去做什么？」 |
| **黎玄同** | **「你……你这是要圈养我？」** |
| **洛水漓** | **「差不多而已。」**（原文：短短的五个字，粉碎了黎玄同对江湖的所有美好幻想） |

> 最后两句是**书名原句**，且完全不涉及身体接触，可安全使用（尺度 🟢）。

### 建议

把片尾钩子从"身世"改为"圈养"——**身世线保留在中段**（玉佩「黎」字 ＋ 左肩半月红印，
用来解释她为什么抓他），**结尾落在书名上**（"你要圈养我？"／"差不多而已"）。
这样观众搜书的动机从"想知道她是谁"变成"想知道圈养之后发生了什么"，**直接对应书名**。
