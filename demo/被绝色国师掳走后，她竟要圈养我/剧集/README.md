## 生成方式（已定案）

**角色图 + 场景图直接生成，不做逐镜冻结关键帧。**

- 每镜挂 1–2 张已有资产板（`REF-...`），配文字提示词把角色放进场景。
- 角色板负责"脸和衣服不变"，场景板负责"地方不变"，提示词负责"这一镜发生什么"。
- 之所以不做关键帧：逐镜出图太慢，角色板 + 场景板的组合已经能锁住一致性。
