## 生成方式（已定案）

**角色图 + 场景图直接生成；11 镜合并为 3 段 × 15 秒，每段一次生成。**

- 每段只挂**场景图 + 角色图**，道具（剑、玉佩）用文字描述，**不挂图**。
- 角色板管"脸和衣服不变"，场景板管"地方不变"，提示词管"这一段发生什么"。
- 之所以不逐镜生成：镜头太多，生成与拼接都费时间。
