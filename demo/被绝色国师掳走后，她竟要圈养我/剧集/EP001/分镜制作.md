# EP001《被绝色国师掳走后，她竟要圈养我》｜分镜制作

> **本片性质**：推广原著小说的**单部短片**，不是系列首集，没有上集也没有下集。
> 采用**冷开**——直接给冲突，不介绍人物。

**尾帧锚定：** 仰角远景，两道身影冲天而起缩成剪影，下方石阶上一点青色仍跌坐仰头；天光空镜收尾。
（不预留续集接口；尾帧的唯一任务是把观众推去搜书名。）

## 基本信息

**集数：** EP001
**剧名：** 被绝色国师掳走后，她竟要圈养我
**出处：** 原著 seq 1–6（对应爆点 HK-01 打脸 + HK-02 国师认亲）
**总时长：** 45 秒
**镜头总数：** 3 个（无过渡镜头，首集冷开）
**单镜头时长：** 固定 **15 秒**，不多不少（三镜统一 15 秒）
**画幅：** 9:16 竖屏（本项目既定参数）
**主题句：** 一个被骂「乡巴佬」的乡下少年，用一拳砸开了神捕司的门，却被当朝国师一把掳走——她盯着他左肩那块半月红印，只说了一句：从今往后，你只能留在我身边。
**一句话梗概：** 黎玄同误了神捕司报名的时辰，被守门捕快辱骂后当场出手把人全揍趴，随即被闻讯赶来的秋月宗弟子李青衣问罪；他一个过肩摔把李青衣摔出，却在此时撞上从天而降的当朝国师洛水漓——她挑起他腰间刻着「黎」字的旧玉佩，一掌碎了他的衣裳，死死盯住他左肩那块半月红印，不答他的名姓，只将他强行带走。
**核心情节点：** 冷开（门关人散）→ 递钱受辱 → 挨骂「乡巴佬」黑化出手 → 一拳砸塌 → 李青衣落地问罪 → 掌击无效、过肩摔 → 国师降临掐喉 → 挑起玉佩见「黎」字 → 碎衣见半月红印 → **圈养宣告（书名钩子）** → 掳走升空
**出场角色：** 黎玄同、洛水漓、李青衣、张三（守门捕快）、李四（小捕快）
