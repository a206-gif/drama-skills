## 生产注意

1. **进视频前裁掉标注区**：部分模型版本会在图上加 `CHARACTER DESIGN SHEET` 一类英文标签。
2. **场景板可复用于其他集**：`REF-09`–`REF-11` 不止 EP001 用。
3. **命名约定**：`IMG-NN` 与 `REF-NN` **一一对应**。
4. **图片会丢**：本目录 PNG 曾被工作区重置清空过一次。**改完图请提交到分支**（见项目根 `README.md`）。
