## 生产注意

1. **角色与场景必须同源画风**：都用加权语法（渲染器＋调色＋材质三组词），只换光态。
   混用中文改图体会出「真人背景 + CG 人物」。
2. **色调必须过锚点**：新图出炉先跑 `python3 设定集/色调校验器.py 图片/新图.jpg`，
   守 **[蓝 > 绿 > 红]**（暖色服装角色与实用光源除外），场景饱和 ≤ 28%。
   详见 [色调基准锚定](../色调基准锚定.md)。
3. **进视频前裁掉标注区**：部分模型版本会在图上加 `CHARACTER DESIGN SHEET` 一类英文标签。
4. **场景板可复用于其他集**：`REF-09`／`REF-14`／`REF-15` 不止 EP001 用。
5. **命名约定**：`IMG-NN` 与 `REF-NN` **一一对应**。
6. **图片会丢**：本目录 PNG 曾被工作区重置清空过一次。**改完图请提交到分支**（见项目根 `README.md`）。
