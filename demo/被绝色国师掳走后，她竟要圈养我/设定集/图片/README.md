## 三条生产注意

1. **尺度靠取景控，不靠提示词**：姜绯凰那条写了 `no slit`，Seedream 仍出成侧开衩＋赤足脚链。
   角色设定图按实出接受；**正片镜头要收敛就改取景**（半身／腰以上／倚坐掩足）。
2. **出图请存 2K**：四栏里最右侧的竖条细节才够裁。
3. **进视频前裁掉标注区**：部分模型版本会在图上加 `CHARACTER DESIGN SHEET` 一类英文标签。

## 命名约定

`IMG-NN` 与 `REF-NN` **一一对应**，引用时用哪个都不会错。
