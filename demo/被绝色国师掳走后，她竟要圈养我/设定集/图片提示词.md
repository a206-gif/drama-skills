## 场景板写法（中文改图体）

本机与 Seedream 都稳定。三段结构：

**第一段｜保留什么**
```
在参考图的基础上做修改：完全保留参考图的画风、光影氛围、材质表现方式与柔光雾感，
只把画面内容换成……。渲染方式、光晕与空气感必须与参考图一致。
```

**第二段｜画面内容**（空间地理 + 最不能丢的固定特征，用 `((…)):1.4` 写死）

**第三段｜空场政策**
```
空场：画面里没有任何人物，没有挂画、没有招牌、没有任何文字。
排除：人物、现代物件、可读文字、视图标签、箭头、水印。
```

## 冻结关键帧（`PLAN-1` … `PLAN-20`）

每镜一张，格式同上但**不出现标注与文字**。EP001 需要 `PLAN-4` … `PLAN-11` 八张，
内容要点见 [EP001 分镜](../剧集/EP001/分镜.md)。

**关键帧的统一要求**：

- 与对应镜的挂图（`REF-...`）**人物一致**：瞳色、发型、服装、配饰都不能偏。
- 与对应镜的**景别一致**：分镜里写的是近景就不能出全景。
- **不加任何文字、序号、边框**——它是给视频模型当起始帧的，不是给人看的版面。
