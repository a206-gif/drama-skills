## 场景板写法（中文改图体·已实测）

三段结构：

**第一段｜保留什么**
```
在参考图的基础上做修改：完全保留参考图的画风、光影氛围、材质表现方式与柔光雾感，
只把画面内容换成……。渲染方式、光晕与空气感必须与参考图一致。
```

**第二段｜画面内容**（空间地理 + 最不能丢的固定特征，用 `((…)):1.4` 写死）

**第三段｜空场政策**
```
空场：画面里没有任何人物，没有挂画、没有招牌、没有任何文字。
排除：人物、现代物件、可读文字、视图标签、箭头、水印。
```

**光态必须写死**——本机实测：只写"正午强光"会出成阴天，要写
`((正午烈日当空，阳光从上方垂直偏斜照下，石板被晒得发白发亮，阴影短而硬、边界清晰)):1.4`，
并在排除里补 `夜晚、阴天、暗调`。

### 已出的三张场景板 + 两张道具板

`REF-09` 神捕司门前长街、`REF-10` 秋月宗山门石阶、`REF-11` 秋月宗竹屋
——**提示词原文见 [图片/README](图片/README.md) 的核对栏**，三张均已验证可用。

`REF-12` 青锋剑与秋月剑的实测：**剑身处要写
`((剑身细长笔直，长度约为剑柄的六到七倍，是长剑而不是匕首、不是短刀)):1.4`**，
否则会出成短剑；护手的弯月纹仍有概率出成圆纹。

`REF-13` 黎字玉佩：`((「黎」字必须清晰可读、笔画完整、方向端正)):1.4`，实测有效。
