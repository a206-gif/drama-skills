# 角色入景提示词

> **要解决的问题**：把角色图 + 场景图直接丢给视频模型，最常见的失败是
> **"演员站在 CG 背景前"**——人物像贴上去的，光影对不上、脚下没影子、色调两层皮。
>
> **正确做法是两段式**：
> ① 先出一张 **角色入景静帧**（下面这套提示词）
> ② 再拿这张静帧当视频的**首帧**生成视频
>
> 视频模型的「首帧」模式会让整段画面从这张图长出来，一致性远高于多图参考。

---

## 一、入景六件套（漏一件就会出贴图感）

把角色放进场景，提示词里必须有这六项：

| # | 件 | 怎么写 | 漏了会怎样 |
|---|---|---|---|
| 1 | **定位** | 他在哪、朝哪、什么景别 | 人物飘在画面中间，与建筑无空间关系 |
| 2 | **光向对齐** | 主光从哪来、阴影朝哪倒 | 人物一脸柔光、场景一片硬阳，两层皮 |
| 3 | **接触阴影** | 脚下有投影、衣摆在地上有影 | 人物像悬空/贴上去 |
| 4 | **环境色反打** | 衣服上带环境光的反射色 | 人物自带棚拍色，与场景割裂 |
| 5 | **共享大气** | 人物身上也蒙同一层尘/雾/光晕 | 场景有雾、人物干净锋利 |
| 6 | **同一台相机** | 同一焦段、同一景深、同一视平线 | 透视对不上，像后期合成 |

**一句话记法**：**光、影、色、雾、焦、位**——六样都要和场景齐。

## 二、负向（专治贴图感）

```
棚拍背景, 孤立打光, 抠图感, 贴纸感, 人物边缘白边, 人物与场景光影不一致, 比例失调, 悬空, 无接触阴影, 灰底影棚, 文字, 水印, 视图标注, 肢体畸变, 手指畸变
```

## 三、挂图顺序与技法

1. **场景图放第一位，角色图放第二位**——先定环境，人物进去就不容易带着影棚底跑。
2. **人物脸漂** → 把角色图提到第一位。
3. **人物与环境脱节** → 把场景图提到第一位，并在提示词里**把光向抄一遍**。
4. **仍然贴图感** → 加一句 `same lighting, same colour grading, same atmosphere as the background`。
5. **不要用角色板当首帧**——角色板是灰底棚拍，直接生成视频会把灰底带进去。

## 五、静帧出来后的检查表

| 检查 | 不合格的表现 | 怎么修 |
|---|---|---|
| **影子** | 脚下没影、影子方向与建筑相反 | 重写「光与影」那段，把方向说死 |
| **色调** | 人物偏暖/偏亮，场景偏冷/偏暗 | 补 `same colour grading as the background` |
| **边缘** | 人物轮廓有一圈亮边或白边 | 负向加 `白边, 抠图感` |
| **透视** | 人物脚尖与地面不贴合，像浮着 | 补 `feet firmly planted on the ground, correct perspective` |
| **大气** | 场景有尘雾、人物高清锐利 | 补 `subject shares the same atmospheric haze as the background` |
| **脸** | 与角色板不一致 | 把角色图提到第一位，负向加 `面容与参考图不一致` |

**过了这六条，这张静帧就可以当视频首帧了。**
