## 一、画风

| 项 | 定案 |
|---|---|
| 风格 | **中国古风 3D CGI**（游戏级渲染），不是二维插画、不是真人实拍 |
| 画风基准 | `画风图/微信图片_20261015005004_111_160.jpg` |
| 提示词骨架 | `(Chinese xianxia 3D CGI:1.3)` ＋ `(Unreal Engine 5 render:1.2)` |
| 出图工具 | **Seedream**（本机模型解析加权语法偏平，已确认模型差异） |
| 光 | `((soft diffused studio lighting, cool muted gray-blue seamless backdrop)):1.3`，柔光雾感棚底 |
| 肤质 | `(delicate porcelain skin SSS:1.2)`，细腻次表面散射 |
| 角色板版式 | 四栏：左半身特写／中正面全身／右背面全身／最右竖条细节 |
| 规格 | 2K（2752×1536 以上），最右竖条细节要够裁 |

**三条禁令**：
1. **不要三维写实照片感**——这句不是要退回二维，是要**古风游戏 CG 的渲染质感**，避免落入"真人写真"。
2. **不要西方奇幻元素**——不加魔法阵、不加洋装、不加西式建筑。
3. **不要画面文字**——不出现任何可读文字、视图标注、水印。

## 五、竖屏构图（9:16）

- **人像安全区**：主要信息放在画面中部 60% 高度内，顶部 12% 与底部 20% 留给平台 UI。
- **单镜一人一动作**：竖屏横向信息少，一个镜头只交代一件事。
- **特写要用**：本书是"脸好看 + 关系张力"型，半身与面部特写占比应高于常规横屏。
- **服装尺度靠取景控**：见 [图片/README](图片/README.md)——提示词压不住开衩，改取景。

## 六、资产板怎么用（已定案）

**角色图 + 场景图直接生成，不做逐镜冻结关键帧。**

- 每镜挂 1–2 张已有资产板：**角色板管"脸和衣服不变"，场景板管"地方不变"**，
  文字提示词管"这一镜发生什么"。
- 换装镜要挂对应造型的板（`REF-02`／`REF-04`）。
- 挂图时若出现英文标注区，先裁掉再挂。
