# 色调基准锚定

> **一句话铁律：本片所有画面，蓝通道 > 绿通道 > 红通道——且只在冷调里做明暗。**
>
> 违反这条，画面就"不是一部片子"。这一节把「感觉」变成可测量、可校验、可粘贴的数字。

**锚点来源（唯一）**：`画风图/微信图片_20261015005004_111_160.jpg`（基础底图）
**辅证**：4 张冷调角色板 `IMG-01 / IMG-03 / IMG-05 / IMG-08` 实测共识

## 一、为什么现在的场景"感觉不对"——实测诊断

把 5 张场景图与基准底图用**同一套算法**测量，漂移是**系统性的**，全部指向同一个方向：

| 图 | 饱和 % | 暗部 蓝/红 | 暗部 蓝/绿 | 中间 蓝/红 | 中间 蓝/绿 | 判定 |
|---|---|---|---|---|---|---|
| **★ 基准底图** | 18.9 | 1.201 | 1.247 | 1.137 | 1.157 | 基准 |
| IMG-09 神捕司长街 | 19.7 | 1.319 | 1.136 | **1.048** | **1.025** | ❌ 中间调丢蓝 |
| IMG-10 山门石阶 | **30.4** | 1.245 | **0.865** | **0.976** | **0.897** | ❌ 绿压过蓝 |
| IMG-11 秋月宗竹屋 | **38.1** | 1.314 | 1.135 | **1.081** | 1.069 | ❌ 饱和超标 |
| IMG-14 祖师堂 | 27.8 | 1.157 | 1.094 | **0.995** | **1.020** | ❌ 中间调丢蓝 |
| IMG-15 秋月宗内院 | 21.5 | 1.171 | **0.928** | 1.065 | **0.964** | ❌ 绿压过蓝 |

### 三处系统性偏移

| 症状 | 证据 | 后果 |
|---|---|---|
| **① 绿通道污染**（最致命） | IMG-10 蓝/绿 = **0.865**、IMG-15 = **0.928**（<1 ＝ 绿压过蓝） | 竹林／草木的绿顶掉冷调，拼上角色板就像两套素材 |
| **② 中间调丢蓝** | IMG-09 中间蓝/红 = **1.048**、IMG-14 = **0.995**（≈中性） | 人物站进去，脸和背景色温打架 |
| **③ 饱和超标** | IMG-11 = **38.1%**、IMG-10 = **30.4%**，基准仅 **18.9%** | 场景抢角色的颜色，画面"脏、艳、廉价" |

### 根因

现有提示词里的调色串是 `(cinematic colour grading, cool muted colour palette, …):1.3`——
**「cool muted」是审美形容词，不是可执行的色彩指令**。模型每次自己理解一遍，于是：

- 场景描述里写了竹子、草木 → 模型把绿画得很足 → **绿压过蓝**
- 「cool」没有指明**哪个通道占主导** → 中间调漂向中性甚至暖
- 没有饱和度上限 → 模型按"好看"给饱和度

**锚定的本质，是把形容词换成通道级指令。**

### 为什么会"感觉不好"的第二层：影调塌陷

调色救不回来的是**影调分布**：

| 图 | 中间调像素占比 | 基准 |
|---|---|---|
| IMG-11 竹屋 | **3.9%**（95.2% 挤在暗部） | 64.3% |
| IMG-09 长街 | **7.9%** | 64.3% |

IMG-09 是「亮到爆的地面 + 死黑的建筑」的**双峰分布**，IMG-11 几乎全黑。这两张即使色调对了，也会显得**平、薄、廉价**——因为中间调没有信息。**这是生成阶段的问题，必须在提示词里解决，不能靠后期**。

## 二、锚点定义

### 2.1 铁律（唯一不可违反项）

```
暗部与中间调：蓝 > 绿 > 红
亮部：允许回到中性（冷调片的正常表现）
```

推论：**任何让绿压过蓝的写法都是错的**，包括"翠绿的竹林""青翠草木""生机勃勃的绿意"。

### 2.2 硬指标表

| 项 | 锚点目标 | 允许范围 | 说明 |
|---|---|---|---|
| **暗部 蓝/红** | ≥ 1.25 | ≥ 1.15 | 阴影必须冷 |
| **暗部 蓝/绿** | ≥ 1.15 | ≥ 1.05 | **绿不得顶掉蓝** |
| **中间 蓝/红** | ≥ 1.20 | ≥ 1.12 | 中间调是脸所在，最要紧 |
| **中间 蓝/绿** | ≥ 1.10 | ≥ 1.05 | 同上 |
| **亮部 蓝/红・蓝/绿** | ≈ 1.03 | ≥ 0.98 | 高光允许中性 |
| **饱和度** | 场景 22% | 场景 ≤ 28% | 基准底图 18.9%；场景超 28% 会抢角色色 |
| | 角色 31% | 角色 ≤ 36% | 角色有服装色，上限放宽 |
| **平均明度** | 昼景 100 | 昼景 80–135 | |
| | 夜景/内景 45 | 夜景/内景 25–100 | |
| **中间调占比** | 昼景 ≥ 40% | 昼景 ≥ 30% | **低于此值画面发闷** |
| | 夜景 ≥ 18% | 夜景 ≥ 10% | |

### 2.3 基准底图与角色板实测值（对照参考）

| 资产 | 饱和 % | 明度 | 暗 蓝/红・蓝/绿 | 中 蓝/红・蓝/绿 | 亮 蓝/红・蓝/绿 |
|---|---|---|---|---|---|
| ★ 基准底图 | 18.9 | 108.2 | 1.201・1.247 | 1.137・1.157 | 1.031・1.057 |
| IMG-03 洛水漓 | 30.1 | 108.3 | 1.651・1.438 | 1.386・1.280 | 1.095・1.078 |
| IMG-05 李青衣 | 34.6 | 88.4 | 1.669・1.228 | 1.410・1.191 | 1.057・1.029 |
| IMG-01 黎玄同 | 26.5 | 99.5 | 1.039・1.022 | 1.139・1.075 | 0.911・0.967 |

## 三、提示词锚定串（直接粘贴）

### 3.1 场景提示词·通用色调段（替换旧版调色串）

**旧写法（弃用）**：
```
((cinematic colour grading, cool muted colour palette, soft bloom, subtle volumetric haze)):1.3
```

**新写法（锚定版，粘贴到每条场景提示词的通用段）**：
```
((cool blue-grey cinematic grade, blue channel dominant over green and red, desaturated muted palette)):1.4,
((foliage, bamboo and grass rendered as desaturated blue-grey tones, warm yellow-green cast fully suppressed, no vivid green)):1.4,
((lifted blue-grey shadows, clean neutral highlights, no crushed blacks, no blown-out whites)):1.3,
((soft volumetric haze and atmospheric depth filling the midtones, visible material detail across all tonal ranges)):1.35
```

**逐句为什么这么写**：

| 片段 | 解决的漂移 |
|---|---|
| `blue channel dominant over green and red` | 把「cool」变成**通道级指令**，直接掐死中间调丢蓝 |
| `foliage, bamboo and grass rendered as desaturated blue-grey tones` | 竹林是本片最大绿源，必须**点名** |
| `warm yellow-green cast fully suppressed, no vivid green` | 明确禁止暖绿——只写"冷"模型仍会画暖绿 |
| `lifted blue-grey shadows` | 阴影提蓝提亮，防影调塌进死黑 |
| `soft volumetric haze … filling the midtones` | **直接对抗影调塌陷**——要求中间调有内容 |
| `visible material detail across all tonal ranges` | 防止大块死黑死白 |

### 3.2 负向串（追加到负向列表）

```
warm yellow cast, golden hour warmth, orange tint, vivid saturated green foliage,
oversaturated, teal-and-orange grade, crushed blacks, blown-out highlights,
flat lighting, muddy midtones
```

> ⚠️ `teal-and-orange grade` 必须排除——它是影视最常见调色，但**暖橙会直接破坏冷调锚点**。

### 3.3 光态替换表（只改光态，其余三组词权重不变）

统一段保持不变，按下表替换**光态句**：

| 光态 | 光态句（替换位置） |
|---|---|
| **正午硬光**（IMG-09 长街） | `((high noon, blazing summer sun directly overhead, short hard-edged shadows, bleached white stone slabs)):1.4` |
| **晨间侧逆光**（IMG-10 石阶） | `((early morning backlight raking through the bamboo, long diagonal blade shadows across the stone steps, cool morning blue in the shadows)):1.4` |
| **月夜烛火**（IMG-11 竹屋） | `((moonlit night, cold blue moonlight from above, a single warm candle as the only warm accent, deep blue-grey shadows)):1.4` |
| **室内油灯**（IMG-14 祖师堂） | `((dim interior lit by a few oil lamps, warm light source against cool blue-grey ambient fill, visible detail in the shadow areas)):1.4` |
| **日间内景**（IMG-15 内院） | `((soft overcast daylight, cool diffuse light, blue-grey shadow fill, no direct sun patches)):1.4` |

> **光态例外条款**：烛火／油灯／灯笼等**实用光源（practical light）**允许暖色，但必须是**画面里的小面积暖点**，环境与阴影仍守冷调铁律。
> IMG-11 竹屋烛火夜景正是此类——它的「暖」是对的，**不要当成缺陷去修**。

### 3.4 写法对照（会出事 → 改这样）

| ❌ 会出事的写法 | ✅ 锚定写法 |
|---|---|
| 竹林翠绿、草木青翠 | **竹林呈去饱和蓝灰调，暖黄绿被完全抑制** |
| cool muted colour palette | **blue channel dominant over green and red** |
| 生机勃勃的绿意 | 删掉。情绪词让模型加饱和度 |
| 高对比、通透、通透感 | 删掉。会推出死黑死白，塌掉中间调 |
| 画面整体偏暖的光晕 | 只保留**点状暖源**，环境保持冷 |

## 四、生成阶段约束（调色救不回来的部分）

以下三项**必须在生成时就解决**，后期无法补救：

### 4.1 中间调必须填充

- **硬要求**：昼景中间调像素 ≥ 30%，夜景 ≥ 10%
- **做法**：在提示词里显式要求**大气介质**——晨雾、浮尘、体积光、湿气、烟
- **为什么**：`soft volumetric haze … filling the midtones` 这句就是干这个的。没有介质，画面只有「光源直射区」和「阴影区」两块，中间断层 → 发闷、发平、显得廉价

### 4.2 饱和度必须在生成时压住

- 后期降饱和会连带把角色的服装色一起洗掉
- **做法**：靠 3.1 的 `desaturated muted palette` + 3.2 的负向串
- **判断**：场景图出炉时，若饱和 > 28%，**建议重出而不是修**

### 4.3 绿源必须点名处理

- 本片三大绿源：**竹林、草木、青苔**
- 光是写「冷调」压不住它们——模型的先验知识里竹子就是绿的
- **做法**：必须逐个点名，见 3.1 第二句

## 五、校验与补救

### 5.1 校验器（随本文件交付）

`设定集/色调校验器.py` —— 校验任何新图是否命中锚点，可选自动校色。

```bash
cd demo/被绝色国师掳走后，她竟要圈养我/设定集

# 只校验
python3 色调校验器.py 图片/新场景图.jpg

# 校验 + 输出校色版（_调色.jpg）
python3 色调校验器.py 图片/新场景图.jpg --fix

# 角色板用（放宽饱和上限）
python3 色调校验器.py 图片/IMG-01.png --kind character --tier day

# 强制光态分档（默认按明度自动判定）
python3 色调校验器.py 图片/新图.jpg --tier night
```

输出示例：
```

                              ↳ 暗部蓝/绿 0.928 < 1.05（绿压过蓝）
                              ↳ ...
```

> 依赖：`pip install pillow numpy scipy`（`--fix` 需要 scipy）

## 六、验收清单

新图出炉时逐条过：

- [ ] **暗部蓝/绿 ≥ 1.05** —— 绿没有压过蓝（最常踩）
- [ ] **中间蓝/红 ≥ 1.12** —— 脸所在的中调是冷的
- [ ] **场景饱和 ≤ 28%** —— 没有抢角色的色
- [ ] **昼景中间调占比 ≥ 30%** —— 画面不发闷
- [ ] **平均明度在档**（昼 80–135／夜 25–100）
- [ ] 竹林／草木呈**去饱和蓝灰**，无暖黄绿
- [ ] 有**大气介质**（雾／尘／体积光）填充中间调
- [ ] 暖色只出现在**光源点**（烛火／灯笼／油灯），未蔓延成整张暖调
- [ ] 无 `teal-and-orange` 感

一条不过 → 用第三节的锚定串**重出**，不要靠后期硬修。

## 附：这套锚点覆盖什么、不覆盖什么

| 覆盖 | 不覆盖 |
|---|---|
| 环境光的冷暖方向与通道次序 | 服装固有色（姜绯凰血红、拔野烈暖褐属**允许的暖色爆点**） |
| 阴影／中间调／高光的色度比 | 道具金属材质的反光色偏 |
| 饱和度与影调分布 | 特定场景的氛围强度（雾浓度等） |
| 绿源（竹林／草木／青苔）的处理 | 人工光源本身的色温（烛火就该是暖的） |

**记住**：这条铁律管的是**光和大气**，不是**把画面变成单色**。片子仍然要有暖点——只是暖点必须来自**光源**或**服装**，不能来自环境调色。
