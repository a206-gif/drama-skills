复读某章：查 `项目开发/source-analysis/_index.json` 里 `chapters[sequence==N]` 的
`line_start` / `line_end`，在根目录那份 txt 里按行号取。

## ⚠️ 为什么这个项目破例进了 Git

仓库原本把 `/demo/` 定义为本地草稿空间、不入库。本项目破例入库，是因为
**图片与成稿曾因工作区重置全部丢失一次**（2026-10-15），其中包括 Seedream 出的角色板
——那些图重跑一次成本很高。

`.gitignore` 里为此项目单独开了例外（`/demo/*` + 反向排除），
`输入/*.txt` 仍排除在外。

**改了东西请提交**：

```bash
git add -A "demo/被绝色国师掳走后，她竟要圈养我"
git commit -m "docs(demo): ..."
git push origin arena/932eaa38-drama-skills
```
