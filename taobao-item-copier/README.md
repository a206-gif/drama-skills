# 淘宝店铺图片提取器

给一个淘宝/天猫店铺链接 → 扫描店内全部宝贝链接 → 从每个商品页提取图片（主图 / 详情图 / 属性图）→ 下载到本地库、在画廊里浏览、勾选打包成 ZIP。

本地单机运行，数据不出你的电脑。**只用你自己的淘宝登录态，不需要开放平台 appkey，不经过任何第三方服务器。**

```
采集端                        本地服务                         产出
浏览器扩展  ──HTTP──▶  扫描整店宝贝链接 → 提取每个商品的图片  ──▶  画廊浏览 / 下载到本地库 / 打包 ZIP
（你的登录态）          （127.0.0.1，数据全在本机）
```

## 先说清楚两件事

**1. 为什么扫描店铺要用浏览器扩展，不能后端直接爬？**
淘宝商品页和 mtop 接口都要登录态，mtop 的签名 `sign = md5(token&t&appKey&data)` 里那个 `token`
取自 `.taobao.com` 域下的 `_m_h5_tk` cookie。本地服务的页面跨域读不到这个 cookie，就签不出名。
扩展跑在你已登录的浏览器里，天然有 cookie、能签名、还能直接读页面 DOM——这是唯一稳定路径。

**2. 合规提醒（重要）**
他人商品的主图、详情图受著作权保护。本工具只用于提取你**有权使用**的图片
（如自有货源、已获授权的素材、1688 一件代发的商品图等），请勿用于盗图、搬运侵权等用途。
滥用导致的后果由使用者承担。

## 安装运行

需要 Node.js 18+（自带 `fetch` 和 `--test`）。

```bash
cd taobao-item-copier
npm install
npm run seed        # 可选：写入演示数据，不连淘宝也能先看界面
npm start           # 打开 http://127.0.0.1:8787
```

控制台顶栏会显示商品数、已下载图片数、扩展是否在线。

## 提取图片的三种方式（按推荐度排序）

### 方式 A：浏览器扩展（推荐，能「给个店铺链接扫全部宝贝」）

1. 打开 Chrome → `chrome://extensions` → 右上角开启「开发者模式」
2. 点「加载已解压的扩展程序」→ 选择本项目的 `extension/` 目录
3. 在淘宝/天猫页面点扩展图标 → 填本地服务地址（默认 `http://127.0.0.1:8787`）
   和采集口令（可选）→ 保存并测试连接
4. 之后：
   - **商品页**：右下角出现 📥 浮标，点「采集」入库，点「补全详情」连详情图 / 属性图一起抓
   - **店铺页**：点「采本页」抓当前页所有宝贝，点「采整店」下发整店扫描任务
   - **控制台**：填店铺链接 → 「开始扫描整店」，实时看进度，扫完宝贝链接自动进画廊

整店枚举有两条策略自动兜底：先走 mtop 店铺宝贝搜索接口（快、字段全），
失败退回 DOM 解析店铺「所有宝贝」页（慢但最耐改版）。

> **mtop 接口名会变。** 如果整店扫描报接口错误：在店铺「所有宝贝」页按 F12 → Network →
> 过滤 `mtop` → 翻一页 → 找到返回宝贝列表的那条请求，把 URL 里的 `api`、`v`、`data`
> 抄进扩展弹窗的「高级：mtop 接口配置」即可，不用改代码。

### 方式 B：粘贴页面源码（不装扩展也能用）

在商品页 `Ctrl+A` → `Ctrl+C`，或 `Ctrl+S` 存成「网页，仅 HTML」，
把内容贴进控制台的粘贴框。店铺页 HTML 也认（自动提取里面所有宝贝链接）。
支持自动识别 HTML / JSON / CSV。

### 方式 C：CSV 批量导入

已经整理好的表格，表头支持中英文：`标题,价格,库存,主图,链接`。

## 画廊：浏览 / 下载 / 打包

扫描或粘贴进来后，商品以卡片画廊展示，每张卡片显示前 4 张图 + 图片总数 + 原商品链接。

- **筛选 / 排序**：按关键词、按店铺筛选；按采集时间或图片数量排序
- **看大图**：点卡片打开灯箱，分组查看主图 / 详情图 / 属性图
- **下载图片**：勾选一条或多条 → 「下载图片」，把远程外链图片抓进本地库
  （按内容 MD5 去重命名，同一张图只存一份；下载后画廊显示本地副本，断网也能打开）
- **打包 ZIP**：勾选 → 「打包下载 ZIP」，得到一个只含图片的压缩包

### ZIP 包结构

**「打包下载 ZIP」（`/api/export/images-zip`，只含图片，最常用）：**

```
001-商品标题/
  1.jpg 2.jpg …        主图，按顺序命名（1.jpg 是封面）
  desc-1.jpg …         详情图
  prop-颜色-白.jpg …    属性图（按属性名命名）
  _链接.txt            该商品的原始链接
002-…/
README.txt
```

**「导出完整素材包」（`/api/export/package`，含数据）：**

```
items/       每个商品一份 JSON（可重新导入本工具）
images/      按商品分目录的图片
desc/        商品详情 HTML
商品总表.csv  UTF-8 BOM，Excel 直接打开不乱码
README.txt
```

> ZIP 只打包**已下载到本地库**的图片。如果还没下载过任何图片，打包会提示你先「下载图片」
> （本地服务不联网抓外链打包，避免把盗链风险带进压缩包）。

```
taobao-item-copier/
├── server/
│   ├── index.js            Express 入口（默认只监听 127.0.0.1）
│   ├── lib/
│   │   ├── store.js        JSON 文件存储（商品库 / 店铺 / 设置）
│   │   ├── parser.js       采集数据解析（商品页 HTML / mtop JSON / 店铺页 / CSV）+ 图片 URL 归一
│   │   ├── model.js        商品模型归一化 + 指纹去重 + 一致性告警
│   │   └── images.js       图片下载落地（MD5 去重 + SSRF 域名白名单 + 3MB 上限）
│   └── routes/             ingest（回传/心跳）· items（商品库/下载图片）· shops（整店扫描/SSE 进度）· exports（CSV/ZIP）
├── public/                 控制台前端（原生 JS 画廊，无构建步骤）
├── extension/              Chrome MV3 扩展（采集端）
│   ├── background.js       mtop 签名、整店枚举、与本地服务通信、扫描整店
│   ├── content.js          商品页 / 店铺页取数、采集浮标
│   ├── popup.html/js       扩展弹窗（连接状态 / 采集当前页 / mtop 高级配置）
│   └── md5.js              纯 JS MD5（MV3 的 SubtleCrypto 不支持 MD5）
├── test/                   45 个测试（node:test，零额外依赖）
├── fixtures/               样例商品页 / 店铺页 / mtop JSON
└── data/                   运行时数据（已 gitignore）
```

## 测试

```bash
npm test
```

45 个用例，覆盖几处最容易出错的地方：
- **扩展 MD5**：标准测试向量 + 与 Node crypto 的模糊测试（mtop 签名的地基）
- **解析**：商品页 HTML、mtop JSON 启发式扫描、店铺页枚举、CSV、图片 URL 归一
- **端到端**：起真实 HTTP 服务，走完采集 → 去重 → 编辑保护 → 整店扫描 → 下载图片 → CSV/ZIP 导出，含采集口令、CORS、SSE

## 安全设计

- 服务默认**只监听 127.0.0.1**，不对外暴露
- 采集入口有**口令校验**（可选），防止本机其他网页往你的商品库塞数据
- 图片下载**只允许淘系 CDN 域名**（alicdn / taobaocdn / tmall / taobao / 1688 / aliimg），避免本地服务被当 SSRF 跳板
- 单张图片有 **3MB 上限**，按内容 MD5 命名天然去重
- `data/` 和 `.env` 都在 gitignore 里，数据不会误提交

## 常见问题

**扫描整店报 mtop 接口错误？**
接口名会变，按上面「方式 A」的提示抓一下当前接口填进扩展选项，或改用 DOM 方式。

**下载图片失败 / 图片拉不到？**
淘宝图片有防盗链，本地服务下载时会带 Referer 并只允许淘系 CDN 域名。个别图拉不到会跳过、不阻断其余。

**沙箱 / 服务器环境里下载不了真实图片？**
本工具的图片下载依赖能访问 `alicdn.com`。在无法联网到淘宝 CDN 的环境里只能用 `fixtures/` 里的样例做离线测试，真实下载需在你自己电脑上跑。

**能不能不用扩展？**
可以，用「方式 B」粘贴页面源码，或「方式 C」CSV 导入。但整店批量扫描需要扩展。

**同一张图会被重复下载吗？**
不会。图片按内容 MD5 命名存储，同一张图跨商品只存一份，省空间也省流量。
