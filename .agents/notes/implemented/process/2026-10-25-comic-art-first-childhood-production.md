# Agent Note: 连续童年先齐底图，再统一排字

Status: implemented

## Problem

创作者明确“A 后续话也制作了先把图都制作完”，不再希望每页出图后停在贴字/下一页确认。现有连续开篇CH002余20个明确童年格、CH003全21格缺图。旧原图有昼夜、衣装、动作差异，不应按文件名硬套；批量大PNG还需控制分支体积。

## Decision

已按新授权建立CH002余20格/CH003全21格共41项图优先队列，正文/类型/事件不改，逐镜同源完善无字提示词；暂停逐页贴字/反复问开工。9旧源按blob核，男童111原尺寸/另8页缩览分审，不因文件名直接套图；保旧脸眼发型，服装按原文换大卫衣。伤侧/新配角造型仅本批美术连续选择，非原著新事实。

本轮实际10次成功出图到工具上限，另3请求被直接限额拒绝、未产图。7整幅用、2只取准确局部、1错内景不用，额外1同瞬间反应裁图，共10项就绪/31排队。错误/局部原因回源披露镜别，不将错误全景绑定或裁图假称新动作。新轮恢复容量不是同范围重新授权，不继续同轮重试，不承诺后台自动完成。

模型大PNG先缓存；项目工具只归档8bit静态RGB/RGBA，保模式/尺寸/全部像素字节而optimize重压缩，记录原始/归档/像素SHA，16bit/旧目标/越界明确拒绝。生成调用、局部裁切与本地归档0次分记。采用图、必要小参考、源/队列/预览持久化，纯退稿缓存不入Git，旧生成时SHA/页快照冻结。

## Alternatives considered

- 继续逐页图文：能早看成页，但用户改为优先齐底图，逐页停顿违背新顺序。
- 旧页直接裁：最快且无新调用，但已见旧04含错误衣装/场面，不能代替当前夜里破屋对质；先看后定。
- 直接扩大到109章/未整合中段：表面范围大，但当前连续稿仅开篇，未定年龄/话头不能伪造完成的后续话。

## Consequences

已交10格真实无字素材/索引/来源，余31明确待工具新轮，不冒称整个用户目标已完成。当前新增第5–7页媒体就位但未排字，旧第2–3页/旧收据/24旧PNG不改。仅有局部可用的整幅生成稿不作成品，源缓存可能丢失，采用像素/源SHA/坐标和历史请求快照永久保留，不承诺重生同图。

收益是图优先推进后续话、限额剩量可续、不被审批循环卡住；代价是单轮容量和逐图内容自看仍在，图齐不等于图文/叙事/实机/平台验收。成年、未定回忆、中段未整合/全109章没有偷扩。价格、实际底层型号/seed未知，不虚报免费。
