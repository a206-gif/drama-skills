# 漫画分镜版式轮换与单镜页

## Problem

第 02–10 话的漫画页全部采用「上中下三等分三格」（`L3-V`）。单页看没问题，连续阅读时
每页结构完全一致，节奏平板，转折点与普通对话页在版式上没有任何差别。
2026-10-21 创作者指出这一点，要求后续不再固定使用上中下三组镜头，并在故事转折点
采用单镜大图的精致插画页，同时明确「不是每话都要有」。

另外，`漫画改编/` 此前没有跨 agent 的状态入口：进度、硬约束、版式使用记录散落在
多份 md 与 git log 里，接手方需要重读大量文件才能继续。

## Decision

1. 新建 `漫画改编/工具/版式库.md`，定义 9 种固定版式：
   `L3-V`（三等分）、`L2-W`（宽幅+特写）、`L3-T`（上大下两小）、`L3-B`（上两小下大）、
   `L4-Q`（2×2）、`L2-D`（左右对开）、`L3-S`（大格+窄条）、`L5-T`（横条+两格+横条）、
   `L-S`（单镜整页）。每种给出 ASCII 结构、适用场景、英文提示词句式。
2. 节奏规则：相邻两页不得同版式；同一版式一话 ≤2 次（`L3-S`/`L5-T`/`L-S` ≤1）；
   每话至少 3 种版式；口诀「对话用多格，情绪用大格，转折用单镜」。
3. 单镜页判定用「转折三问」，≥2 项为是才允许；一话 ≤1 页；
   `L-S` 属「页」不属「CG」，不占《1-30 章漫画契约》里全批 ≤3 张的 CG 预算。
4. `PRODUCTION_SYSTEM.md` 增加第二十八章；`制作契约` 第 1 条同步改写。
5. 新建 `漫画改编/记忆存档.md` 作为唯一当前状态入口，含：当前状态、硬约束清单、
   版式记录、待办、append-only 操作日志。以后每次操作都要更新它再提交。

## Alternatives considered

- **全话统一改成四格**：同样会形成新的固定节奏，只是把"三"换成"四"，问题原样存在，故不用。
- **按情绪自由切格、不立固定组合**：创作者要的是"不同固定组合"而非完全自由排版；
  自由排版难以用提示词稳定复现，且不同 agent 接手会各写一套。固定代号 + 上限更容易执行与检查。
- **把单镜页计入 CG 预算**：会让第 11 话之后几乎无法使用单镜页（全批仅 3 张），
  且单镜页仍需贴字、承担正常叙事页功能，与"独立封面级 CG"性质不同，故分开计。
- **另建独立 memory 仓库**：跨仓同步成本高，且创作者希望随作品一起版本化，故放在项目目录内。

## Consequences

- 收益：页间节奏有变化；转折点可以用整页大图承载冲击；版式可被提示词精确描述，
  不同 agent 产出可对齐；接手方读一份 `记忆存档.md` 即可继续。
- 代价：一话需要额外做版式分配（哪页用哪种），排分镜耗时增加；
  贴字坐标不能沿用旧话，每页都要用 `debug_panels` 重测 `panel_rects`；
  `L3-V` 之外的新版式尚未经过实际出图验证，可能需要按实测补充提示词措辞。
- 已完成的第 01–10 话不回溯重做：重做成本高，且创作者已确认 09/10 入库图可用。
