# Agent Note: 未齐页时的单格贴字证明

Status: implemented

## Problem

创作者选A，仅为现有成年首格套用参考式贴字；同页其余图仍缺。现有通用preview按完整页选择，不能把一格当完整页，也不该造空白占位或另立假首话。首格源类型是第三人称旁白与来客画外对白，不是女主内心；遗照也不是发言者。

## Decision

已在项目工具增加受限单格复现脚本，读取全话真实布局/话头并保留相邻核对，用现有letter_metrics/draw_lettering处理准确格ID的全部文字；仅接本项目静态RGB PNG且无image_rect，其他形式明确拒绝，不扩成通用任意图层SDK。按当前格984×432导出PANEL名、范围/来源收据，不输出假PAGE，不使用占位图。完整源/类型/字体路由不变，画外泡尾靠侧缘，不指遗照；旁白维持旁白字体，不因正文有人名而套主角内心字色。输入/字体/布局/代码/输出均记录SHA，先成批暂存，失败或目标已存在不覆盖。

## Alternatives considered

- 临时拼一张竖版完整页：可直接走现有page preview，但会制造缺图空白/把一格放大冒充翻阅页，丢失局部范围。
- 给公共排版器新增多格任意选择协议：可长期复用，但本轮只是一个现有素材的局部应用，不应扩大公共接口/版式语义；先在项目内明确受限复现。
- 徒手贴字不留来源/复现：最快，但容易把已有旁白误改内心、下一轮无法核同源正文和字号。小脚本只承担确定性排字/校验，不创作故事。

## Consequences

已交付`制作成果/成年首格-v5/PANEL-001-01.png`、来源/范围收据与说明，984×432 RGB，747459B；保第三人称旁白/来客画外对白、两段34px，实际字体均为默认黑体，不造主角台词。初试上角环境字争读后改较低阅读行，短尾指右缘不指遗照。原画、五稿152文字与旧15PNG/四成年任务不改，0新模型调用。

收益是缺图时也能看真实格的贴字、且不会把它升级成整页；代价是受限项目工具仅接当前RGB PNG与无EXIF/image_rect的embedded布局，不是公共单格SDK，未来接回完整页还须重排/审阅读。关键肖像/背影主体/手与文字外像素同取景相等只是本地创作自检，不等于图像语义/平台或独立验收。README/交接/规范/记忆与同轮通用skill已回写，旧v2及童年v4/v5收据保历史。
