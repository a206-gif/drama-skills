# Agent Note: 弹性漫画页、局部实图试排与skill技巧沉淀

Status: implemented

## Problem

创作者已认可童年画风，明确独幅通常用于重要转折、普通页多镜且布局不固定。规则此前仅落项目档案，现要求回写skill，后续优化技巧同轮归入skill，每轮交付给下一步选项。首话末页候选等高双横格会遮实际人物/动作；整话其余图未齐，不能用假首话绕过真实交接或冒称全话媒体通过。

## Decision

- static-comic主工作流/页叙事/新增production-learning写入CMC-25/26：弹性分格、素材不等于发布页、主锚/参考纠偏、图字空间与预检、同轮技巧回写及轮末可执行选项。通用技巧不夹带本书专名/素材，按适用范围/实测或待验证分级。AGENTS固化本会话每次回复给下一步选项。
- 以已有两图重排首话末段：PAGE-008重生独幅，PAGE-009介绍/同瞬间反应镜与推广尾栏。反应图从旧原图[580,120,810,430]裁切，推广底本地纯色；无新图像生成调用，不改已认可脸/画风。
- 源/排版现为9页/20格/24TEXT；24个正文不删改，3个末页TEXT按新页号迁移。收养待续引用指向真实009-01/02，下一话仍接回答；推广身份用准确短签，非故事的解释留说明。五稿当前54页/129格/153文字块，非成品页数。
- 可选image_rect用格内正面积整数矩形分离图片区与文字白带/侧栏，校验越界/类型；省略仍原样等比铺满。文本坐标仍相对整格，不用额外白底假格凑数；异形布局仍不冒称支持。
- preview --page/preview_plan仅选择明确存在且不重复的页，按原序导出；先查全话结构与实际上话，再查所选媒体。范围标记随库计划保留，CLI/库都回preview_rendered、原话号、全话页数和episode_media_checked:false。全话render媒体闸门不变，事务式输出/不覆盖/缺字超框拒绝不变。
- 交付制作成果/实图试排-v3两张1080×1440 RGB PNG及来源/看图说明，实际查看两页和360宽近似缩览。修正叙述断行、长尖尾与搜书断句；v1/v2退缓存，不覆盖或混作选项。
- 成年四项交接内容不变，仅刷新全源SHA/布局快照；首格贴字内存重绘PNG哈希与旧v2一致。新两页用当前真源重渲染得到完全相同PNG哈希，源/布局/派生绑定可追溯。

## Alternatives considered

- **只记项目档案**：改动最小；不满足创作者要求在skill复用，因此把通用规则落技能，项目数据留项目。
- **强把原双横格塞满文字**：不改页数；会遮脸/抱持或迫使缩字。用有职责的转折页与承接页，不视为固定两页公式。
- **新建假的首话/独立篇作局部render**：复用旧入口最少代码；会破坏交接/媒体声明。新增明确局部范围而保留真实CH001。
- **只在CLI补局部标记**：输出路径简单；库调用可能误报成全话rendered。范围随preview_plan传递并由render本身报告，增加直接库回归。

## Consequences

- 可迁移制作优化进入skill，后续同轮更新而不只聊天记忆；轮末选项不代替执行已授权任务，也不自动触发新费用。
- 增加11项确定性行为回归，覆盖窗口边界/默认兼容、页选择/顺序、全结构及实际上话检查、缺选页/缺其他页的区别、局部CLI/库范围、嵌套范围、损坏晚失败回滚与不覆盖。不是仅断言文案包含关键词。
- Python3.11/Pillow11.3完整765 tests：737通过、28跳过；当前63漫画+5小说共68正常/优化通过。标准库隔离selftest、153文字块实际CJK/3话相邻记录、ruff/diff、来源/图/派生/成人快照及本地链接通过。
- 固定控制器对基线4ac970965ce967d83f23c6c8eed78f9d5ba044d2离线核验通过；core1.0.1/digest a1b1107520046f6e6e26c5921dab744a30d4412769bf318a7250fd77a64aed36相对前轮已验证值不变，static-comic0.1.0仍excluded，未发布。
- 全话媒体仍按预期在PANEL-001-02缺图拒绝；局部两页自查不是整话/独立review/手机平台或发布验收。当前无3.9运行时，未复跑下限；未上传/commit/push。

创作者后续明确翻转本项目呈现：旧实白名签/独立白字区不采用，改画内半透明字与主角全文字体；旧决定保历史、labelled兼容仍在，见[画内贴字与故事优先](2026-10-25-comic-embedded-lettering-and-story-first.md)。
