# Agent Note: 参考图式椭圆对白、矩形内心与细分隔

Status: implemented

## Problem

创作者补充明确图参考，要求气泡/字体/字色/位置表明人物与叙述，现页外白边/格间白缝太宽。v4虽然已取消姓名标签与独立白字区，仍有24px外边/格缝和硬编码3px黑框，内心为无框大字、对白为圆角大块，与参考的紧凑矩形/椭圆形式不符。

## Decision

只取参考的视觉语法：对白椭圆、内心/必要叙述轻半透明矩形贴角，男女主全文专属字体与同色系保持，不画姓名标签。按类型配置对齐/字色/细描边，避免所有文字同一粗白描边；边框宽度显式可设0，已交付新v5两页满幅无外边，第9页实际3px白分隔。源/六块正文/原画字节不变，图像比例随每页内容选，不套固定三横格。旧v4留历史，新v5与来源/像素证明分别输出。

## Alternatives considered

- 仅缩小24px白缝：最少改动，但3px黑框、圆角大块与无框粗描边字仍不符合新参考。
- 所有页面套参考三格同高：贴近表面结构，但用户既定多镜布局不固定，不能为了样式增加无意义镜头。
- 直接用参考原图/原字：无需重排，但其角色/年龄/剧情未核且不是本段，限定为排字参考。

## Consequences

已输出真实v5 PNG与含布局/输入输出/渲染器SHA的收据；已看原尺寸探针/360缩览，五分镜与原画字节不变。类型配色/对齐/描边、无框与3px分隔像素、旧默认兼容的7个行为回归及152实际字体检查已落地。13个未齐图候选仅增框保40px，不宣称整话排版。新样式换用34–36px是主动选择而非自动缩字；保留v4及旧SHA，原画认可不变。

收益是更贴参考且画面占比更高；代价是椭圆安全区较小，需要逐图重排，浅字/透底仍须看背景。不把一次参考的数值升级为通用硬公式，不新生图或平台上传。

## Validation

3.11/Pillow11.3完整787 tests：759通过/28跳，90漫画专项优化与独立标准库selftest通过；152实际字体/三话相邻、实际PNG格缝/透明底边、五分镜与原图不变、旧v4和当前v5重渲染哈希、相关本地链接、ruff/diff及固定控制器离线清单通过。结果是局部创作自检，不是独立审查或实机/平台验收；当前未重跑3.9。不创建PR/合并/上架。
