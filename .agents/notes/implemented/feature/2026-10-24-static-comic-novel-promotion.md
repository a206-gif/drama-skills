# Agent Note: 静态漫画以原著推广与准确搜书为默认目标

Status: implemented

## Problem

创作者补充：小说改编后的静态漫画是小说推文，全部创作选择服务于推广原著、促使读者搜索并阅读原著，而不是将原著完整漫画化。前一轮的[分页漫画决定](2026-10-24-static-comic.md)解决了媒介与排版，但通用的“本话结果或悬念”没有明确原著体验取样、剧透边界、准确书名与搜书承接。

## Decision

- 对本次小说改编路径明确默认目标为原著推广，不追求全书覆盖或替代阅读；用户明确选择完整漫画化时另记目标，不偷偷混用。
- 在同一创作简报里确定原著卖点及来源、目标读者、要展示的小兑现、需保留到原著阅读的核心问题、停止位置和理由；不把营销判断或固定页数写进几何校验器。
- 增加推广参考与 CMC 规则：钩子与读书理由有原著依据，保留的答案确实在原著中存在或明确未知，不编造爽点、恋爱关系或反转；不靠虚假内容和虚假免费/完结等声明吸引搜索。
- 记录准确书名、作者（已知时）、经确认的原著阅读平台（有时）与搜索词，区分作品名和本篇标题。推广模式的搜书提示是最终漫画中的独立文字块，默认在末页；发布文案复用同一定位，不把必需提示只藏在简介里。
- 沿用单一正文与现有排版接口：推广提示仍是 `TEXT-*` 旁白块，JSON 只引用 ID；更新纯合成的两页样例和版式，保持像素输出、付费确认与不上传边界不变。
- 同步默认调用、核心发现路由和使用说明；原始几何决定保留，与本目标细化互链。

## Alternatives considered

- **只在最终回答记住推广目标**：改动最少，不影响技能。然而独立安装、下一轮继续和模板调用都会丢失目标，因此将目标写入工作流与简报。
- **每格都加书名，或只卡在高潮前不给任何回报**：曝光和悬念更显眼。但会挤占剧情、无法展示原著的真实阅读体验，也易成为纯诱饵；因此以真实卖点、必要铺垫、小兑现和准确搜书承接组织内容。
- **增加推广配置、CTA 专用 JSON 类型和自动转化评分**：便于自动统计。但会建立第二份书名/正文真相，并用数字冒充营销效果；保留 Markdown 真源，语义与平台可检索性由人工核验。

## Consequences

- 收益：选段、开场、结尾、视觉和文案有共同的原著阅读目标，漫画能引导到准确作品，而不是只有泛泛的“未完待续”。
- 代价：需要创作者确认真实书名、使用权限与可选平台，可能限制剧透与选段。工具不能验证书名真实性、营销效果或平台审核；这些保留为明确待办，不声称已经验证。

## Verification

- Python 3.11.2 与 Python 3.9.24 分别运行全套测试：各 724 项，696 通过、28 跳过；强制安装 Pillow 并开启渲染必跑检查，27 项静态漫画回归没有跳过。
- 增加“已规划末页搜书文字不可漏掉”和“独立搜书旁白真实渲染到末页”两项行为测试；断言按文字 ID 与像素结果，不锁定营销措辞。绕过 ID 绑定守卫时，漏掉末页提示的负向测试按预期变红。
- 两页合成分镜、7 格、7 个文字块使用真实中文字体与合成格图完成 PNG 冒烟测试，并检查搜书区域实际有文字像素。没有使用真实小说或调用出图服务；测试图片、字体和日志均在仓库外缓存，不进入 Git。
- 独立安装自测（含漏搜书块变异）、ruff、diff 空白检查、固定中央控制器按基线执行的 ClawHub 离线清单核验全部通过。核心仍为同一未发布变更的 1.0.1，内容锁已刷新；新增技能仍 excluded，未执行任何发布。
- 几何与像素回归只证明交接结构和文字输出；本轮无真实原著、读者测试、平台检索或转化数据，未声称原著忠实、推广效果或平台审核已经验证。
